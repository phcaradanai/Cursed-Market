## วิธีใช้

- กฎล่าสุดที่ผู้ใช้ยืนยันมีลำดับเหนือข้อเสนอเก่าและพฤติกรรมโค้ดที่ยังตามไม่ทัน
- ก่อนผูก effect เข้าสินค้า ให้อ่านกฎของระบบที่เกี่ยวข้องและข้อห้ามในคลัง effect
- ประเด็นที่ระบุว่า “ยังไม่ตกลง” ต้องคงสถานะนั้นไว้ ห้ามอ้างว่าผู้ใช้อนุมัติค่าหรือวิธีตัดสินแล้ว
- ใช้หนึ่ง turn ในเอกสารเป็นหนึ่งรอบพบพ่อค้า/encounter สำหรับอธิบายตารางเวลา ไม่ใช่หนึ่งคลิกหรือหนึ่ง phase ย่อย การเทียบคำนี้กับจังหวะจริงยังต้องยืนยันก่อนลงระบบเวลา
- งานรอบนี้เป็นเอกสาร ไม่มีการปรับ runtime, UI หรือข้อมูลเซฟ
