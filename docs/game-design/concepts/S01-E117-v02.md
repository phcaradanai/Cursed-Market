# S01 / E117 / v02 — บริบทก่อนตัดสินใจปิดประตู

สถานะ: **superseded draft** · ผู้ใช้เห็นว่ารกเกินไป ให้ใช้แนว minimal v01 ร่วมกับดูประตู/tooltip ในv03

## สิ่งที่แก้จากผู้ใช้

- เห็นประตูทั้ง3 หมายเลข และชื่อ/ภาพพ่อค้าก่อนเลือก
- Fixture: ประตู1ออร์ก ประตู2แวมไพร์ ประตู3ออโตมาตา เป็นตัวอย่าง state ไม่ใช่การตรึงพ่อค้าทุก run
- จ่าย2เครดิต+1พลัง: ปิดประตู2 เหลือ1และ3
- รับD02หมอกราคา: ปิดประตู1 เหลือ2และ3
- รับD06อุปกรณ์หนัก: ปิดประตู1 เหลือ2และ3
- ยังไม่แสดงว่าประตูใดปิดจริงก่อนส่ง action และไม่เปิด goods/ราคา/ความแท้/คำสาปที่ยังไม่รู้

## หลักฐาน

`generatePortals` สร้าง3 portal และ `resolveCore2Event` ปิดเฉพาะ index1 เมื่อ door first หรือ index0 เมื่อ door second ประตูอื่นคง state เดิม UI จริงต้องอ่าน portal IDs/merchant/disabled จาก state ปัจจุบัน ไม่ hardcode ชื่อหรือบังคับให้ประตู3เปิดถ้าถูกปิดมาก่อน

ลด artwork ผู้เฝ้าด่านเพื่อคืนพื้นที่ให้ข้อมูลตัดสินใจ ใช้3คอลัมน์ตรงกันและปุ่มระดับเดียวกัน ไม่มี scroll ภาพ edit จากv01ด้วย imagegen ไม่ใช่ runtime implementation หรือการอนุมัติภาพ
