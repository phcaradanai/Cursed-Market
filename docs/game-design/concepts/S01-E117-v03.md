# S01 / E117 / v03 — minimal event + outcome preview

สถานะ draft ยังไม่อนุมัติ ยังไม่ลง runtime

กลับไปใช้ความเรียบและ artwork ของ v01 เพิ่มปุ่มดูประตูและ tooltip/highlight ของตัวเลือก ภาพที่บันทึกเป็นสถานะ hover จ่ายค่าผ่าน ไม่ใช่ tooltip ที่ค้างตลอดเวลา

ดูประตูต้อง reuse หน้า/คอมโพเนนต์เลือกประตูที่มีอยู่แล้ว ไม่ออกแบบหน้าใหม่ ระหว่าง event ค้างใช้โหมดอ่านอย่างเดียว ไม่ส่งคำตอบ/เข้าประตู/รีเซ็ตเวลา กดกลับคืนเหตุการณ์เดิม

Hover/focus หรือปุ่มข้อมูลบนจอสัมผัสแสดงผลก่อนเลือก ใช้ชื่อพ่อค้า/หมายเลข/disabled state จริง ไม่เปลี่ยน HUD จริงก่อนส่ง action

ภาพ portal-peek ที่สร้างเกินความจำเป็นไม่ได้ลงทะเบียนเป็นแบบอ้างอิงและไม่ใช้แทนหน้าเดิม ต่อไปตรวจของเดิมก่อนสร้างทุกครั้ง
