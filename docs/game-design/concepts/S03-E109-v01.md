## การจัดวางและปฏิสัมพันธ์

Artwork พ่อค้าฝั่งซ้าย เนื้อหาและต้นทุนฝั่งขวา; ฐานตัวละครชิดขอบล่าง ตัดเฉพาะส่วนล่าง ส่วนบน/ซ้าย/ขวาซ้อนกรอบได้ ปุ่มคู่ใช้ความสูง/ความกว้าง/รัศมีมุมเท่ากัน ช่องไฟเท่ากัน ไม่มี page scroll

ต้นทุนชีวิตและคำเตือนอยู่บนหน้าหลัก ส่วนรายการผลสุ่มอยู่ใน tooltip ของปุ่มข้อมูล เปิดได้ด้วย hover/focus และปุ่มข้อมูลสำหรับจอสัมผัส ไม่บังปุ่มยืนยันและไม่ส่ง action เมื่อดูข้อมูล

“ซ่อนไว้ดูโต๊ะ” ใช้พฤติกรรม tuck ของ EventModal เดิม กลับไปดูโต๊ะที่มีอยู่; คง event/คำตอบที่ยังไม่ส่ง/พฤติกรรมเวลาจริง ไม่ปฏิเสธหรือรีเซ็ตเวลา ต้องมีทางกลับสู่เหตุการณ์ที่ค้าง

ก่อนส่ง action ตรวจทรัพยากรและ eligibility ล่าสุด ปิดการกดซ้ำระหว่างส่ง หากไม่ผ่านแสดงเหตุผล ห้ามแก้ HUD จริงตาม preview ห้ามเปิดความแท้/คำสาป/ราคาจริงของสินค้า

## ขอบเขต

ภาพร่างแสดงสถานะ tooltip เปิดเพียงหนึ่งอัน ไม่ใช่กล่องค้างทุกครั้ง ข้อความ/ค่าจริงต้องมาจาก state และ event terms ภาพไม่พิสูจน์ responsive, runtime implementation หรือ balance; ยังไม่มีภาพจับ E109 จริง
