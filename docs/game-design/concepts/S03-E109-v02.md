# S03 / E109 / v02 — ลดรูป เพิ่มพื้นที่ตัดสินใจ

สถานะ draft ยังไม่อนุมัติ ไม่ใช่ภาพจับเกม; ใช้แทนร่าง v01 ในทะเบียนภาพปัจจุบัน

ผู้ใช้ขอให้ลดขนาดรูป ใช้พื้นที่เนื้อหามากขึ้น และเข้า theme comic ชัดขึ้น จึงลดน้ำหนักภาพพ่อค้าจากประมาณ45% เหลือประมาณ28–30% ของพื้นที่เนื้อหา ใช้เส้นหมึกเข้ม cel shading และพื้นลาย halftone/ทแยงสีแดงอย่างเบา ไม่เพิ่มกรอบแฟนตาซีอลังการ

เนื้อหาใช้พื้นที่ที่คืนมาจากภาพ จัดต้นทุนทันทีและผลในอนาคตเป็นคู่ที่จัดแนวเท่ากัน ปุ่มยอมรับ/ปฏิเสธมีขนาดและช่องไฟเท่ากัน มุมมนระดับเดียวกันทุกกล่อง ข้อความไม่ซ้ำและไม่มี page scroll; ฐานพ่อค้าไม่เลยกรอบล่าง

ใช้กติกาและ interaction จาก [v01](S03-E109-v01.md) ทุกข้อ: จ่ายชีวิต2ทันที เมื่อเลือกพบ Vampire ครั้งหน้าสุ่มรับเพียงหนึ่งผลที่ใช้ได้ หากจบรันก่อนพบอีกไม่ได้ผลตอบแทน Tooltip เป็นสถานะ hover/focus หรือเปิดจากปุ่มข้อมูลบน touch ต้องไม่ล้น viewport/บังปุ่ม และไม่ส่งคำตอบ

HUD/footer ใช้ชุดเดิม ไม่สร้าง phase หรือกลไกใหม่ ภาพยังไม่พิสูจน์ขนาดบนทุกจอหรือผลการทดสอบ runtime
