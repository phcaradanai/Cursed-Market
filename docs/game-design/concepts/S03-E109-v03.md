# S03 / E109 / v03 — symmetry pass

สถานะ draft ยังไม่อนุมัติ เป็นภาพออกแบบ ไม่ใช่ภาพจับ runtime

ผู้ใช้เห็นว่า v02 ดีขึ้น แต่ต้องปรับ symmetry อีกครั้ง จึงคงขนาดภาพพ่อค้า/โทน comic เดิม ปรับเฉพาะ grid และความสมดุล:

- Artwork กับเนื้อหามีแนวบน/ล่างร่วมกัน ช่องไฟกลางเท่ากับ padding หลัก
- กล่องต้นทุนและผลตอบแทนใช้สองคอลัมน์เท่ากัน ทั้งความกว้าง ความสูง และระยะภายใน
- ปุ่มยอมรับ/ปฏิเสธใช้สองคอลัมน์เท่ากัน ขอบซ้าย/ขวาและเส้นกึ่งกลางตรงกับกล่องข้อมูลข้างบน
- กำหนดช่องไฟ24 และ radius12 เป็นสัดส่วนภาพร่าง เมื่อพัฒนาต้องใช้ token/component กลางของเกม ไม่เพิ่มรัศมีเฉพาะหน้านี้
- Tooltip อยู่ใน viewport ไม่ทับคำเตือนหรือ action เปิดด้วย hover/focus/ปุ่มข้อมูลบน touch ไม่ใช่กล่องค้าง
- ฐานพ่อค้าไม่เลยกรอบล่าง ไม่มี page scroll

กติกาเดิมตาม [v01](S03-E109-v01.md): จ่ายชีวิต2ทันที สุ่มเพียงหนึ่งผลที่ใช้ได้เมื่อเลือกพบ Vampire ครั้งหน้า จบเกมก่อนพบอีกไม่ได้ผลตอบแทน การซ่อนใช้ EventModal tuck เดิม ไม่ปฏิเสธ/รีเซ็ตเวลา/ข้ามเหตุการณ์

ภาพ bitmap ใช้ตรวจทิศทาง ไม่ใช่หลักฐานว่าระยะทุกพิกเซลเท่ากัน การลง UI ต้องกำหนด equal grid และตรวจขนาดจริงอีกครั้ง ยังไม่เปลี่ยนโค้ดเกมหรือกติกา
