# S03 / E109 / v04 — พ่อค้าทะลุกรอบสามด้าน

สถานะ draft ยังไม่อนุมัติ ภาพร่างเท่านั้น ไม่เปลี่ยน runtime

ผู้ใช้ย้ำรูปแบบพ่อค้าที่เคยตกลง: **ฐานรูปต้องชิดและตัดเสมอขอบล่าง ห้ามล้นล่าง ส่วนบน ซ้าย ขวาทับหรือทะลุกรอบได้** ไม่ขังรูปไว้ในสี่เหลี่ยมทั้งตัว และไม่ใช้ fade ขอบรูป

คงสัดส่วนรูปที่ลดแล้วและ layout v03 ลดขอบบน/ด้านข้างของการ์ดพื้นหลังแดงไว้หลังตัวละคร เพื่อให้ศีรษะ ผม ไหล่/แขนมี silhouette ทับขอบชัดเจน เส้นกรอบอยู่หลังรูป ไม่พาดทับร่าง พื้นหลังบริเวณศีรษะเห็นฉากตลาดเดิม ฐานรูปกับกรอบมี baseline ร่วมกันโดยไม่มีช่องว่างหรือส่วนล่างเกิน

ไม่เพิ่มขนาดรูปกลับ ไม่ให้ส่วนที่ทะลุไปทับข้อความ/ปุ่ม พื้นที่ด้านขวา/ต้นทุน/tooltip/คำเตือน/ปุ่มคู่และกติกายึด [v03](S03-E109-v03.md) เดิม ต้องรักษา equal grid และ token กลางเมื่อพัฒนาจริง

ภาพอ้างอิงไม่ได้พิสูจน์การ clip ทุกความละเอียด ต้องตรวจฐานรูปจริงและการซ้อนด้านข้างใน UI เมื่อ implementation
