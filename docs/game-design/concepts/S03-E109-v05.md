# S03 / E109 / v05 — ไม่มีกรอบพื้นหลังพ่อค้า

สถานะ draft ยังไม่อนุมัติ ไม่ใช่ภาพจับ runtime

ผู้ใช้ให้เอากรอบพื้นหลังพ่อค้าออกทั้งหมด จึงลบเฉพาะการ์ดแดง/ลาย halftone และเส้นขาวหลังตัวละคร ใช้ cutout พ่อค้าวางบนฉากตลาดโดยตรง ไม่มีกรอบ portrait หรือ fade ขอบ

คงกรอบรวมของหน้า ขนาดรูปที่ลดแล้ว ฐานรูปชิด/ตัดเสมอขอบล่าง ส่วนบนซ้ายขวาลอยทับได้โดยไม่บังข้อมูล คงข้อมูล/action/tooltip และ symmetry ของ [v04](S03-E109-v04.md) ไม่เพิ่มกลไกและไม่แก้โค้ดเกม

กฎนี้แทนที่การมีการ์ดแดงหลังพ่อค้าในร่าง v02–v04; ภาพเหล่านั้นเก็บเป็นประวัติ ไม่ใช่แบบปัจจุบัน
