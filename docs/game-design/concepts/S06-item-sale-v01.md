# S06 / item-sale v01 — รายละเอียดสินค้าและประกาศขาย

สถานะ: concept draft ตามภาพผู้ใช้ 2026-10-29; ยังไม่อนุมัติและยังไม่แก้ runtime. เป็น substate ของ S06 ไม่ใช่หน้า flow ใหม่ ไม่แทนโต๊ะซื้อขาย v05

## โครงภาพ

ใช้กรอบกลางเดียวกับกระเป๋าจาก comic-frame.css: ขอบ/ตำแหน่ง/ความสูง/รัศมีร่วม HUD และเมนูล่างเดิม. Headerชื่อสินค้าและปิด. ภายในสองคอลัมน์เท่ากัน ระยะ24pxและbaselineร่วม ไม่มี scroll, dropdown, เส้นปะ หรือกรอบซ้อนหลายชั้น

ซ้ายรูปสินค้าเดียวแบบcomicเส้นเข้มมุมperspectiveบนผ้าแดง ขอบล่างชิดฐาน ด้านบน/ข้างอาจล้นบริเวณภาพได้ ไม่fadeภาพ. แถบข้อมูลที่รู้แล้ว3ช่องเท่ากัน มูลค่าจริง/ความแท้/คำสาป ตามด้วยที่มาและราคาพ่อค้า ไม่มีรูปพ่อค้าซ้ำ

ขวาสถานะการมองเห็น คำระบุความแท้และคำสาปที่ผู้ขายเลือกอย่างละ3ตัวเลือก และค่าแถม ปุ่มประกาศขาย/โชว์ให้ดูขนาดเท่ากัน. แยกคำระบุผู้ขายจากผลตรวจอย่างชัดเจน ข้อความท้าทาย/ราคา/disabled reasonsเข้าผ่านtooltipกลางที่ hover/focus/Escape และไม่ส่งactionจากการดู

## ข้อมูลและเงื่อนไขจริง

ภาพนี้ยาชำระล้าง NPC ราคา52 เครดิต ยังไม่ได้ประเมินและยังไม่มี listing; knowledgeทั้ง3เป็น? ไม่มีการเปิดเผยข้อเท็จจริงลับ. maySell=false ทำให้ประกาศขายและค่าแถมปิด พร้อมเหตุผล แต่โชว์ให้ดูยังใช้ได้ถ้าไม่ติดgame action lock

Share runtimeรองรับคำระบุเฉพาะ shopItem (NPCและchallengeเปิด); ถ้าไม่เข้าเงื่อนไขให้ใช้พื้นที่ขวาเป็นข้อมูลที่เหมาะกับ state ไม่สร้างสิทธิใหม่. ของคลังขายได้เฉพาะไม่locked. ค่าแถมจำนวนเต็ม0–1000และไม่เกินcredit จ่ายเมื่อขายสำเร็จ. ปุ่มไม่ใช่การตั้งราคาขายNPCและไม่เพิ่มactivation

สถานะอื่น: listed-shopแสดงแก้คำระบุ; listed-ownedไม่ประกาศซ้ำ; show-onlyแสดงว่าโชว์อยู่แล้ว; listingที่มีแล้วมีเก็บกลับ ใช้พื้นที่actionเดิมแทนเพิ่มแถวจนล้น. การประกาศ/โชว์/เก็บกลับใช้share actionเดิม ไม่ใช่propose/respond; ข้อเสนอจริงเปิดจากเมนูข้อเสนอของโต๊ะ
