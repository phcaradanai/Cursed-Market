# S06 / table v05 — โต๊ะซื้อขายและการเดินระหว่างโต๊ะ

ผู้ใช้สั่งเริ่ม implementation แล้ว; ภาพเป็นเป้าหมายหน้าตา ไม่ใช่หลักฐาน runtime รายละเอียดการลงจริงอยู่ implementations/S06-trade.md

## State และเส้นทาง

- เริ่มที่โต๊ะสินค้าในร้านพ่อค้าที่เราประเมินแล้ว ไม่ใช่ของที่เราเป็นเจ้าของ ใช้กรอบหลักเดียวและ tabletop วางภาพสินค้า3–4ชิ้นต่อหน้า
- ลูกศรขวา overlay เปลี่ยนชุดสินค้าแบบวน เมื่อมีหลายหน้าเท่านั้น; ไม่มีหลายหน้าซ่อน/ปิดพร้อมเหตุผล ไม่วางสำเนาซ้ำในหน้าเดียว
- ปุ่ม overlay กระเป๋ากับลูกศรลง กลางล่าง: transition ลงสู่ของในคลังเรา ไม่เปลี่ยน phase หรือเป็น action ซื้อขาย
- เมื่ออยู่คลังเรา มีปุ่ม overlay บนเพื่อย้อนสู่สินค้าในร้านพ่อค้าที่ประเมินไว้ ใช้ item ownership และสิทธิ์จริงแยกจากร้าน
- ที่โต๊ะเรา ผู้เล่นอื่นเป็นปุ่ม avatar overlay เรียงลงฝั่งซ้าย หนึ่งปุ่มต่อคน ไม่ใช้รูปเผ่าพ่อค้าแทนผู้เล่น
- คลิกผู้เล่นเพื่อ transition ไปโต๊ะของเขา แสดงเฉพาะรายการที่เขาเปิดให้เราเห็น/ซื้อได้ ไม่อ่านคลังลับ
- ที่โต๊ะคนอื่น ลูกศรซ้ายวนหน้ารายการเมื่อมีมากกว่าหนึ่งหน้า ลูกศรขวากลับโต๊ะเรา ต้องกลับโต๊ะเราก่อนจึงเลือกผู้เล่นรายอื่น; ซ่อน rail ผู้เล่นขณะอยู่โต๊ะคนอื่น

## การนำเสนอ

กรอบและ padding กลางเท่ากันทุกด้าน สินค้ากระจายน้ำหนักเท่ากัน ไม่มี card รอบทุกชิ้น ปุ่ม overlay กลมมีพื้นหลังดำโปร่ง fade เบาเฉพาะพื้นหลังเพื่อให้เห็น ไม่ fade ตัวสินค้า ภาพไม่ซ้ำทั้งซ้ายและขวา กดของจึงเปิดข้อมูล/action ที่เกี่ยวข้อง ไม่แสดงทุกฟอร์มพร้อมกัน

ภาพ v05 แสดงเฉพาะ state เริ่มต้น ตัวเลข/สินค้าเป็นตัวอย่าง ไม่ใช่การเพิ่ม catalog หรือเปิดเผยราคาจริงที่ยังไม่รู้ เมนูล่างยังใช้ได้ ไม่มี scroll

## เงื่อนไขที่ต้องปิดก่อนพัฒนา

จำนวน3หรือ4ขึ้นกับพื้นที่จอ กำหนด minimum hit target ให้ overlay แม้รูปดูเล็ก คงชื่อ/tooltip/focus label, ลด motion ตามการตั้งค่า, ไม่รีเซ็ตเวลา และไม่ส่ง action ระหว่างเปลี่ยนโต๊ะ กรณีว่าง/คนออก/รายการหายต้องแสดงและ clamp page อย่างถูกต้อง ต้องกำหนดว่ากลับจากโต๊ะเพื่อนคืนหน้าเดิมหรือหน้าแรกก่อน implementation (ยังไม่ใช่กฎยืนยัน)

การซื้อ/ขายจริงยังใช้ share/propose/respond และสิทธิ์เดิม โต๊ะเพื่อนที่เปิดให้ชมอย่างเดียวต้องไม่แสดงว่าซื้อได้ เก็บข้อเสนอค้างและทางเข้า action ไว้ ไม่ทำให้ navigation ส่งเงินหรือของเอง
