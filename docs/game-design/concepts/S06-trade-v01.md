# S06 / trade v01 — หน้าซื้อขายระหว่างผู้เล่น

ภาพร่างรอ feedback ไม่ใช่ภาพเกมจริง ไม่ได้แก้ runtime; สร้างใหม่ตามคำขอผู้ใช้โดยเทียบภาพจับ C03 และ `TradeListing`/action ที่มี

## แนวทาง

ซ้ายรายการสินค้า ขวาข้อมูลรายการที่เลือกและข้อเสนอ ใช้กริดสมดุล ปุ่มและมุมมนร่วมกับเกม ภาพสินค้าเป็น cutout 2D บน UI ไม่มี page scrolling รายการยาวต้องแบ่งหน้าหรือใช้ทางเลือกที่เห็นได้ ไม่ซ่อนรายการถาวร

## ต้องแก้ก่อนนำไปพัฒนา

- ภาพใช้ชื่อ «ของที่เปิดให้ซื้อ» แต่ปุ่ม «เปิดให้เพื่อนซื้อ» แสดงสถานะยังไม่เปิด จึงต้องแยกรายการของฉันที่ยังไม่เปิด/เปิดแล้ว กับรายการที่ผู้อื่นเปิดให้ชัด; ปุ่มและเจ้าของต้องเปลี่ยนตาม state ไม่ยืนยันว่ารายการนั้นเปิดแล้วทั้งที่ยังไม่เปิด
- สินค้าในร้าน NPC ที่ผู้เล่นอื่นเปิดให้ซื้อ มีราคาพ่อค้าและอาจมีค่าเสนอให้ผู้ประเมิน: แสดงยอดรวม/ต้นทุนตาม state จริงก่อนส่งข้อเสนอ สินค้าของผู้เล่นเองเป็นอีกกรณี ไม่ทำให้ดูว่าทั้งหมดเป็นสินค้าในร้าน NPC
- แสดงข้อเสนอเข้า/ออกและปุ่มตอบรับหรือปฏิเสธตามผู้มีสิทธิ์ รวม disabled reason; ต้องรองรับเลือกของแลก เงื่อนไข ท้าทาย และสิทธิ์บังคับซื้อเมื่อเกี่ยวข้อง โดยไม่แสดงทุกอย่างพร้อมกันตลอด
- ไม่แสดงมูลค่า ความแท้ คำสาป หรือข้อมูลสินค้าใดที่ผู้เล่นยังไม่รู้ นอกจากข้อมูลที่ระบบเปิดให้เห็นจริง ไม่ใช้ตัวอย่างภาพแทนแค็ตตาล็อกใหม่56
- จบซื้อขายใช้ action เดิม ตรวจผลของค้าง/เงื่อนไขและรอผู้เล่นอื่น; ตำแหน่งปุ่มยังเป็นข้อเสนอในภาพ ไม่ได้เปลี่ยนกฎเกม

HUD/footer และองค์ประกอบใช้ component กลาง; ตัวอย่างชื่อ/ภาพ/ราคาจำลองเพื่ออธิบาย layout ไม่ใช่คำยืนยันข้อมูลในเกมหรือการรับรอง balance
