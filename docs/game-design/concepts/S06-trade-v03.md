# S06 / trade v03 — symmetry

ภาพร่าง รอ feedback ยังไม่อนุมัติและไม่ได้แก้เกม ผู้ใช้แก้ว่า v02 ยังไม่สมมาตร จึงปรับกรอบซ้ายขวาให้กว้างใกล้เคียงกัน แนวบน/ล่างตรงกัน รายการสูงเท่ากัน ปุ่มคู่และขอบส่วนรายละเอียดใช้กริดร่วมกัน พร้อมเปลี่ยนชื่อเป็นสินค้าในร้านที่ผู้เล่นประเมิน เพื่อไม่สื่อว่าเป็นสินค้าที่ผู้เล่นเป็นเจ้าของ

กฎและ state จริงยึด [v01](S06-trade-v01.md): แยกของที่ยังไม่เปิด/เปิดแล้ว/ของผู้เล่นอื่น, ราคาพ่อค้าและค่าเสนอ, สิทธิ์ตอบรับ/ปฏิเสธและข้อมูลลับ การเสนอแบบนี้ยังไม่แสดงทุก state ในภาพเดียว

ใช้ grid สองคอลัมน์เท่ากันและ token/component กลางเมื่อพัฒนา ตรวจขอบ/gap/padding/ปุ่มใน UI จริงตาม viewport; ภาพ AI เป็นทิศทาง ไม่ใช่หลักฐานว่าขนาดเท่ากันทุกพิกเซล
