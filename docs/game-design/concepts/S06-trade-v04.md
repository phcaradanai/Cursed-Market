# S06 / trade v04 — ลดกรอบและใช้ระยะร่วม

ภาพ concept รอ feedback ไม่แก้ implementation รอบนี้ ผู้ใช้ปฏิเสธความไม่สม่ำเสมอของ padding/border และจำนวนกล่องที่มากเกินไป

ใช้กรอบหลักเดียว คอลัมน์เท่ากันแบ่งด้วยเส้นบาง แถวบน/ล่างใช้แนวร่วม ไม่มีกรอบซ้อนรอบชื่อ ราคา สถานะ หรือ facts ปุ่มใช้ขนาด/เส้น/รัศมีร่วมกัน

แสดงสถานะเปิดตัวเลือก: สินค้าที่เลือกอยู่ช่องบนซ้ายเสมอ ช่องล่างซ้ายเป็นตัวเลือกความแท้/คำสาป/ค่าแถม ส่วนขวาคงข้อมูลและ action ไม่ขยายดันลง รูปสินค้าแสดงเพียงซ้าย ไม่มี scroll

ตัวอย่างสินค้าไม่ถูกประเมินจึงปิดประกาศขาย ต้องมีเหตุผลที่เข้าถึงได้ก่อนกด คำระบุของผู้ขายไม่ใช่ความจริงที่ตรวจแล้ว ไม่เปิดข้อมูลลับ ค่าและสถานะต้องอ่านจาก runtime ตามเดิม ใช้ Share/Trades และ component กลาง ไม่สร้างกฎหรือ action ใหม่

ตัวเลข padding24/gap16/เส้น1px ในภาพเป็นแนวทาง ต้องใช้ token กลางและวัด UI จริงก่อนอ้างว่าตรงทุกจอ
