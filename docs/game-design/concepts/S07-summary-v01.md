# S07 / summary v01 — สรุปผลท้ายช่วง

ภาพร่างรอ feedback ไม่ใช่ runtime หรือ phase ใหม่ เป็น presentation-proposal ของผล settleEncounter ก่อน S08 หรือผล Collector ที่ S12

ใช้กรอบเมนูเดิม ระยะ24/gap16เป็นสัดส่วนภาพร่าง เมื่อพัฒนาใช้ token และ component กลางให้ทุกแนว/ขนาดปุ่มคู่เท่ากัน ภายในสองคอลัมน์แสดงรายการเหตุผลและยอดก่อน→หลัง แถวตรงกันทั้งบน/ล่าง ไม่มี page scrolling

ตัวอย่างชีวิต4→3เป็นข้อมูลจำลอง ไม่ใช่กฎว่าทุกช่วงเสียชีวิต1 ต้องใช้ผลที่เกิดจริงจากเกมและสาเหตุที่ผู้เล่นรู้ ไม่มีการเปิดความแท้/คำสาป/ราคาสินค้าลับ และไม่รวมเครดิตเติมช่วงที่ยังไม่รับ

ปุ่มดูบันทึกเปิดเมนูเดิม ปุ่มไปหน้ารับเครดิตเป็นการนำทางการแสดงผล ไม่สร้าง action จ่ายเงินหรือจบ phase ใหม่ หากเกมจบจาก Collector ข้ามไปผลที่เหมาะสม ไม่บังคับให้ทุก encounter ต้องผ่านหน้านี้

สถานะที่ต้องรองรับก่อน implementation: ไม่มีผลเปลี่ยนแปลง, หลายรายการ (แบ่งหน้าอย่างกระชับ), ผู้เล่นตาย, เกมจบ, ยังรอผู้เล่นอื่น และ reconnect; ภาพร่างไม่ถือว่ากลไกเหล่านี้ทำแล้ว
