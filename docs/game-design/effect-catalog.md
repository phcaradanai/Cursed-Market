# Cursed Market — คลัง effect 75 แนว

อัปเดต: 2026-10-28 (Asia/Bangkok)

อ่าน [กฎและ logic เกม](rules-and-logic.md) ก่อนนำรายการไปใช้

## สถานะและวิธีอ่าน

เป็นคลังออกแบบจากการสนทนาวันที่ 2026-10-26 ปรับข้อจำกัดให้ตรงกฎล่าสุดวันที่ 2026-10-28 ประกอบด้วย 75 แนวใน 25 กลุ่ม มีทั้งการใช้ effect เดิมและการเสนอจุดเชื่อมใหม่ ไม่ใช่ 75 effect ที่พัฒนาเสร็จหรืออนุมัติทั้งหมด

มี [ร่าง relation กับสินค้าใหม่ 56 แบบ](logic-item-relations.md) (8 พ่อค้า × 7 แบบ) สำหรับ review coverage และ balance แล้ว การจับคู่ยังเป็นข้อเสนอ ยังไม่ใช่ binding ใน runtime และยังไม่กำหนดตัวเลขจริง

| รูปแบบ | ความหมาย |
|---|---|
| ถือ | ทำงานขณะถือและมีสิทธิ์รับ passive |
| ใช้ | ผู้เล่นกดใช้ เลือกเป้าหมาย และจ่ายต้นทุนตามที่กำหนด |
| เงื่อนไข | Trigger หลังเหตุการณ์ที่ตรวจยืนยันแล้ว เช่น ชำระเงินกู้ครบหรือชนะประมูล |
| ทบทวน | มีความเสี่ยงเปลี่ยนกฎหลัก ต้องตกลงขอบเขตก่อนพัฒนา |

### กฎล่าสุดที่ครอบคลุมทุกแถว

- ขโมยต้องเข้าร่วมเป่ายิ้งฉุบ ปฏิเสธไม่ได้: การป้องกันไม่ให้เริ่มดวลหรือยกเลิกอัตโนมัติไม่ใช่ผลที่อนุมัติ
- ดอกเบี้ยฐาน 10% และคิดเฉพาะเงินก้อนเดิมที่อยู่ครบช่วง ข้อเสนอฐาน 4%/เพดานรวม 8% ถูกแทนที่แล้ว
- Collector Wishlist มี 5 ช่องจากของที่ขอ 3 และสุ่ม 2 รอ 2 turn เปิดดูได้ 1 และต้องจ่ายซื้อ ห้ามแอบเพิ่มสิทธิ์หรือแจกฟรีด้วยรายการในคลัง
- สัญญา Wishlist รับซื้อของ NPC เดิม กับ Wishlist ขอซื้อจาก Collector เป็นคนละระบบ
- คะแนนพิเศษเป็นกฎใหม่ การสร้าง effect เปลี่ยนคะแนนหรือเพิ่มตัวนับต้องตกลงก่อน

## แนวจัดชุดสินค้า

หนึ่งสินค้าอาจมี **ผลขณะถือ + ผลกดใช้ + ข้อเสียหรือสิ่งที่ต้องแลก** แต่ไม่จำเป็นต้องมีครบสามอย่างทุกชิ้น

- สายการเงิน: อายุเงินฝาก ดอกเบี้ย พื้นที่คลัง และการคืนเงินกู้
- สายพ่อค้า: ตรวจข้อมูล ประเมิน ต่อรอง ตลาดมืด สัญญา และคู่ค้าใหม่
- สายเสี่ยง: เป่ายิ้งฉุบ อาชญากรรม ตราบาป และรางวัลทายเหรียญ
- สายเอาตัวรอด: พลัง ชีวิต เศษชีพจร ภัยและสถานะ
- สายสะสม: Rarity จำนวนชนิด ความไว้ใจ และโบนัสสต็อก

รายการนี้เป็นแนว build ที่เสนอ ยังไม่ได้จัดให้พ่อค้าคนใดหรือสินค้าใดโดยเฉพาะ

## ข้อมูลที่ต้องกำหนดก่อนพัฒนาแต่ละ effect

1. ID สินค้าและ ID effect; เป้าหมายและระบบที่รองรับ
2. Trigger ที่แน่นอน และเหตุการณ์ที่ไม่นับ
3. ค่าฐาน ต้นทุน ระยะเวลา จำนวนชาร์จ และเพดานรวม
4. การคูณ rarity/สำเนา รวมถึงสิทธิ์แบบจำนวนเต็ม เช่น ช่องคลังและจำนวนครั้ง
5. การสะสมกับ kind เดิม ต่าง kind สถานะ และความสามารถพ่อค้า
6. แหล่งเงิน/สินค้าที่จ่าย และวิธีเมื่อธนาคารไม่พอ
7. การเปลี่ยนเจ้าของ ฝาก vault ค้ำประกัน ตาย และจบเกมส่งผลอย่างไร
8. สิ่งที่ผู้เล่นรู้ก่อนเลือก และข้อมูลที่ยังต้องปกปิด
9. กฎป้องกันใช้ซ้ำ ส่งคำสั่งซ้ำ reconnect หรือวนซื้อขายเพื่อปั๊มผล
10. Log ที่บอกต้นทาง ค่าเดิม ค่าที่ปรับ ผลจริง และเหตุผลที่ไม่เกิดผล

## ประเด็นที่ต้อง tune เพิ่มตามกฎใหม่

- ฐานดอกเบี้ย 10% ทำให้ E46 ต้องประเมินใหม่ ไม่ใช้ค่าหรือเพดาน 8% ที่เคยเสนอ
- E40/E41/E54 ต้องผ่านกฎบังคับ RPS ห้ามทำเป็น “ปฏิเสธการขโมย”
- E55–E57 เป็น Wishlist NPC เดิม การเพิ่ม effect Collector Wishlist ต้องออกแบบเพิ่มแยก โดยคง 3+2, รอ 2 turn, เปิดดู 1 และซื้อด้วยเงินจริง
- โบนัสซื้อ/ขายและ E15–E24 ต้องออกแบบร่วมกับสถิติคะแนนผู้นำเพื่อไม่ให้วนซื้อขายปั๊มทั้งเงินและคะแนน
- E27–E30/E69 ต้องแยกค่าชั่วคราวกับค่าจริงที่ใช้ตัดสินรางวัลความไว้ใจและ rarity
- รางวัลใช้พลังชีวิตที่เสียสะสม (`lifeLost`) ไม่ใช่จำนวนครั้งตาย; ออกแบบเพดาน/การนับความเสียหายที่จ่ายเองและการรักษาวนก่อนผูก effect
