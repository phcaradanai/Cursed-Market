# สัญญาบริการวิญญาณ — ออกแบบจากคำอธิบายผู้ใช้

วันที่ 2026-10-29 · สถานะ: กติกาหลักและฐานชำระเงินจากผู้ใช้; อัตราแปลงคะแนนและขอบเขตงานบางส่วนยังรอยืนยัน; ยังไม่ลง runtime

## เป้าหมายและขอบเขต

คนตายเล่นต่อในโลกวิญญาณและรับรายได้จากงานที่ทำสำเร็จให้คนเป็น ไม่ได้ร่วมชนะหรือรับอันดับของคู่สัญญา ข้อเสนอผู้ร่วมชัยชนะก่อนหน้านี้ถูกปฏิเสธ: ผู้เล่นอันดับสามต้องไม่กลายเป็นผู้ชนะเพราะจับคู่กับอันดับหนึ่ง จบเกมทุกสายพร้อมกันตอน Collector ตามกฎเดิม ผู้เล่นตายได้ครั้งเดียว

ผู้ใช้ยืนยันเพิ่ม 2026-10-29 ว่ารายได้บริการเป็นคะแนนพิเศษ จึงแทนที่ข้อจำกัดเดิมที่คะแนนทุกชนิดหลังตายต้องหยุด: คะแนนเดิมจากช่วงมีชีวิตแยกจากคะแนนพิเศษที่ทำงานได้จริงหลังตาย ไม่ใช่ได้รับอันดับตามผู้ว่าจ้าง อัตราแปลงเครดิตเป็นคะแนนและสูตรรวมคะแนนยังต้องยืนยัน

## กติกาที่ผู้ใช้ระบุ

### 1. ปลดสิทธิ์ให้บริการ

- เริ่มจากยังไม่เปิดรับงาน ต้องชนะมินิเกมติดตามการ์ดก่อน
- มีการ์ดสินค้า/พ่อค้า 4 ใบ เปิดให้ดูหนึ่งใบ แล้วสลับตำแหน่งให้มองตาม
- ทายตำแหน่งของใบเดิมให้ถูกจึงมีสิทธิ์ถูกเรียกใช้บริการ
- ทายผิดเล่นใหม่ได้เรื่อย ๆ ไม่ต้องรอ turn และไม่ขวางคนเป็น
- เมื่อเปิดบริการแล้ว ให้ผู้รอดชีวิตทุกคนใช้บริการได้
- เมื่อทำงานของผู้ใช้บริการทั้งหมดสำเร็จ ต้องกลับไปชนะมินิเกมก่อนเปิดบริการรอบใหม่

### 2. ตกลงสัญญา

- ทุกช่วง ผู้มีชีวิตเรียกบริการวิญญาณได้
- ผู้มีชีวิตเห็นสินค้าสุ่ม 3 ชนิดให้เลือกเป้าหมาย
- ราคาซื้อสุ่มช่วง 90%–120% ของ base; ผู้ว่าจ้างเห็นราคาที่ต้องจ่าย
- ค่าจ้างบริการตกลงกันก่อน เริ่มที่ 0 เครดิตได้
- ผู้ว่าจ้างจ่ายราคาสินค้าและค่าจ้างเมื่อส่งมอบสำเร็จ ไม่มีการจ่ายตอนรับงาน
- ส่วนแบ่งวิญญาณเท่ากับ 10% ของ base และหักออกจากราคาสินค้า ไม่คิดส่วนแบ่ง 10% เพิ่มบนยอดที่ผู้ว่าจ้างต้องจ่าย รายได้บริการนำไปคิดคะแนนพิเศษ

### 3. ตามหาของที่ร้าน Skeleton

- มี NPC พ่อค้า Skeleton ในโลกวิญญาณ เสนอของ 3 ช่อง เปิดให้เห็น
- ซื้อได้เฉพาะสินค้าที่ตรงกับเป้าหมายผู้ใช้บริการ ไม่ซื้อของอื่นเก็บเอง
- เล่นเป่ายิ้งฉุบเพื่อเปลี่ยนสินค้าของช่องที่เลือก
- แต่ละช่องนับแพ้แยกกัน ช่องที่แพ้จะหมดสิทธิ์เปลี่ยน แต่ช่องอื่นยังเล่นได้
- เล่นช่องที่ยังมีสิทธิ์ต่อได้จนแพ้ หรือซื้อของที่ต้องการได้
- ถ้าแพ้ครบทั้งสามช่อง ต้องรอคนเป็นจบช่วงปัจจุบันก่อนเริ่มช่วงหน้า
- โลกวิญญาณทำงานอิสระจาก turn คนเป็น คนเป็นไม่ต้องรอวิญญาณเล่นจบหรือกดพร้อม

Skeleton เป็นบทบาท NPC บริการเพิ่มเติมในโลกวิญญาณ ไม่ใช่การอนุมัติเปลี่ยน catalog หลักจาก 8 พ่อค้า × 7 สินค้า การใช้สินค้าใหม่ 56 ชิ้นกับร้านนี้ต้องระบุ mapping ตอนวางแผน

## วงจรสถานะที่เสนอเพื่ออธิบายกติกา

รอปลดสิทธิ์ → ติดตามการ์ดชนะ → เปิดรับบริการ → ตกลงงาน → ตามหาสินค้า → ส่งมอบและรับเงินเฉพาะงานสำเร็จ → งานในชุดครบ → กลับไปปลดสิทธิ์

หากแพ้ RPS ทุกช่องระหว่างมีงานค้าง: รอช่วงถัดไป โดยงาน/การชำระเงินไม่ถือว่าสำเร็จเอง ไม่ใช้การกลับไปเล่นมินิเกมปลดสิทธิ์เป็นทางรีเซ็ตช่องแพ้ในช่วงเดิม

วงจรนี้เป็นคำอธิบาย ไม่ใช่ข้อสรุปเรื่องจำนวนงานพร้อมกันหรือรอบปิดรับงาน

## สูตรแบ่งยอดที่ยืนยัน

กำหนด B = base, P = ราคาสินค้าสุ่มในช่วง 90%–120% ของ B, F = ค่าจ้างที่ตกลง (เริ่ม 0 ได้), C = 10% ของ B

- เมื่อส่งมอบสำเร็จ ผู้ว่าจ้างจ่าย P + F
- ส่วนแบ่งจากราคาสินค้าให้วิญญาณ C; ราคาสินค้าส่วนที่เหลือ P − C
- รายได้จากงานของวิญญาณ C + F นำไปคิดคะแนนพิเศษ โดยยังต้องยืนยันอัตราแปลง
- ไม่บวก C ซ้ำเข้าราคาที่ผู้ว่าจ้างจ่าย และไม่สร้างรายการชำระจนกว่าจะส่งมอบสำเร็จ

ตัวอย่าง B=100, P=110, F=5: ผู้ว่าจ้างจ่าย 115; ส่วนสินค้าที่เหลือ 100; ส่วนแบ่งวิญญาณ 10 บวกค่าจ้าง 5 รวมรายได้ 15 ไม่ใช่เรียกเก็บ 125 ตัวอย่างนี้ยังไม่อนุมัติว่า 15 หน่วยรายได้เท่ากับ 15 คะแนน

## รายละเอียดระบบเงินที่ยังเปิด

- อัตราแปลงรายได้เป็นคะแนนพิเศษ และค่าจ้าง/ส่วนแบ่งมีน้ำหนักเดียวกันหรือไม่
- การปัดเศษส่วนแบ่ง 10% ของ base (ยังไม่ยกกฎ floor ของดอกเบี้ยมาบังคับกับบริการโดยอัตโนมัติ)
- ผู้ว่าจ้างเงินไม่พอเมื่อส่งมอบ: ล้มเหลว ค้างงาน หรือวิธีอื่น; ไม่ถือว่าจ่ายแล้วและไม่ให้ส่งของฟรี
- คะแนนพิเศษเข้าผลรวมตอน Collector อย่างไร; ต้องแสดงแยกจากคะแนนเดิมและป้องกันนับรายได้ซ้ำทั้งเครดิตและคะแนน

## กติกาประกอบที่ยังไม่ระบุ

- สามช่อง Skeleton ใช้ร่วมกันทุกสัญญาหรือแยกต่อสัญญา; ซื้อสำเร็จแล้วช่องเติม/ล็อกอย่างไร
- RPS เสมอ, ขอบเขตสุ่มสินค้า, โอกาสพบเป้าหมาย และราคาที่ตกลงเปลี่ยนระหว่างตามหาหรือไม่
- จำนวนงานต่อผู้ว่าจ้าง/ต่อช่วง ใครยืนยันค่าจ้าง และเมื่อใดถือว่าปิดชุดงานเพื่อกลับไปเล่นมินิเกม
- คนเป็นจบช่วง เปลี่ยนใจ ตาย หรือเกมจบขณะตามหาของ: งานค้างและเงินสำรองจัดการอย่างไร
- กดส่งมอบซ้ำ/reconnect ต้องไม่เกิดของหรือรายได้ซ้ำ และห้ามเปลี่ยนผู้รับหลังตกลงโดยไม่มีคำยืนยัน
- มินิเกมสลับการ์ดต้องตรวจฝั่ง server ให้ถูกต้องโดยไม่ส่งเฉลยแฝงให้ client; ความยากต้องเล่นได้จริงบนอุปกรณ์ที่รองรับ

## หลักฐานบาลานซ์ที่ต้องเก็บ

- เวลาเฉลี่ย/การกระจายในการชนะมินิเกมและตามหาของ; จำนวนช่วงที่ผู้ว่าจ้างต้องรอ
- อัตราสำเร็จตามประเภทสินค้า/จำนวนงาน/จำนวนวิญญาณ และความถี่ที่แพ้ครบสามช่อง
- ราคาจ่ายรวมสุ่มซื้อ + ค่าจ้าง (10% หักในราคาสินค้าแล้ว) เทียบทางซื้อปกติ และแหล่งเงินของส่วนต่าง
- รายได้จากงานและคะแนนพิเศษที่เกิดจริง เพื่อพิสูจน์แรงจูงใจโดยไม่ทำให้การตั้งใจตายคุ้มกว่ามีชีวิต
- การทำสัญญาอุ้มเพื่อน/ราคาศูนย์/โอนเงินย้อนกลับ/ซื้อของตัวเอง และแรงจูงใจตั้งใจตาย

เอกสารนี้ไม่อนุมัติค่าเป้าหมาย ความน่าจะเป็น หรือสูตรชำระเงินที่ยังเปิดอยู่
