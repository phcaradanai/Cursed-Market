# สัญญาบริการวิญญาณ

อัปเดต 2026-10-31 · กติกาต่อไปนี้ผู้ใช้ยืนยันแล้วและเชื่อม runtime ใน `apps/comic/` ดู [หลักฐานและข้อจำกัด](implementations/ghost-delivery-progress.md) และ [ผลตรวจ](../ui-system/ghost-functional-verification.json)

## เป้าหมาย

ผู้เล่นตายได้ครั้งเดียว แต่เล่นโลกวิญญาณต่อได้จนเกมจบ คนเป็นไม่ต้องรอวิญญาณ ไม่มีการร่วมชนะหรือรับอันดับตามผู้ว่าจ้าง รายได้บริการเป็นคะแนนพิเศษจากงานสำเร็จ แยกจากคะแนนปกติและตัดสินพร้อมกันตอน Collector

## ปลดสิทธิ์และรับงาน

1. วิญญาณเริ่มจากยังไม่เปิดบริการ ต้องชนะเกมติดตามการ์ด4ใบ เปิดเป้าหมายให้ดูหนึ่งใบแล้วสลับ ทายผิดเริ่มใหม่ได้ไม่จำกัด
2. เปิดบริการให้คนเป็นทุกคน ผู้ว่าจ้างเห็นสินค้า3ชนิดพร้อมราคาสุ่ม90–120%ของbase เลือกหนึ่งชนิดและกำหนดค่าจ้างตั้งแต่0 วิญญาณตอบรับหรือปฏิเสธก่อนตามหา
3. ผู้ว่าจ้างมีงานค้างกับวิญญาณแต่ละคนได้1งาน ไม่จ่ายล่วงหน้า ราคาที่เห็นถูกผูกกับคำสั่งจ้าง หากข้อเสนอเปลี่ยนต้องเลือกใหม่ และเก็บเงื่อนไขที่ตกลงแล้วไว้ตลอดงาน
4. ทำงานในชุดครบแล้วต้องกลับไปชนะมินิเกมก่อนเปิดบริการใหม่ เมื่อผู้ว่าจ้างตายให้ยกเลิกงานนั้นโดยไม่คิดเงินหรือคะแนน ถ้าไม่มีงานอื่นค้างต้องกลับไปมินิเกมเช่นกัน

## ร้าน Skeleton และเป่ายิ้งฉุบ

- เปิดสินค้า3ช่อง ซื้อได้เฉพาะชนิดตรงกับงานที่ตอบรับ ห้ามซื้อเก็บเอง
- เลือกช่องและเล่นเป่ายิ้งฉุบเพื่อเปลี่ยนของ: ชนะเปลี่ยนของ เสมอเล่นใหม่ แพ้ล็อกเฉพาะช่องนั้น
- แพ้ครบ3ช่องรอช่วงคนเป็นถัดไป ห้ามรีเซ็ตผ่านมินิเกมหรือ reconnect งานยังค้างและไม่มีการจ่ายเอง
- การทำงานปัจจุบันใช้3ช่องร่วมกันต่อวิญญาณ ซื้อสำเร็จเติมช่องนั้น และรีเซ็ตช่องแพ้เมื่อขึ้นช่วงคนเป็นใหม่ อื่นๆไม่ขวาง turn คนเป็น
- Skeleton เป็นบทบาทบริการเพิ่ม ไม่เปลี่ยนพ่อค้าหลัก8คน×7สินค้า Runtime นี้ใช้ catalog ที่เกมมีอยู่ ไม่ถือว่าอนุมัติ mapping ของใหม่56ชิ้นจากรูปหรือชื่อ

## ส่งมอบและคะแนน

B=base, P=ราคาที่ตกลง (จำนวนเต็มตั้งแต่ceil(0.9B)ถึงfloor(1.2B)), F=ค่าจ้าง, C=floor(0.1B)

- ส่งสำเร็จครั้งเดียวจึงให้สินค้าและหักผู้ว่าจ้าง P+F ผ่าน ledger เดิม
- C หักภายใน P แล้ว ไม่คิดเพิ่มบนยอดผู้ว่าจ้าง วิญญาณได้ C+F เป็นคะแนนพิเศษ อัตรา1เครดิตรายได้=1คะแนน ไม่เพิ่มเป็นเงินในกระเป๋าซ้ำ
- ถ้าผู้ว่าจ้างเงินไม่พอ ให้รอเติมก่อนส่งมอบ ไม่ส่งฟรี ไม่จ่ายบางส่วน และไม่ยกเลิกเพราะเงินไม่พอ
- ผู้ว่าจ้างตายหรือเกมจบ: งานที่ไม่สำเร็จถูกยกเลิกโดยไม่มีเงินหรือคะแนน ไม่มีของ/รายได้ซ้ำจาก retry/reconnect
- Collector รวมคะแนนพิเศษครั้งเดียวหลังตัวคูณคะแนนปกติ Status แสดงประมาณการด้วยสูตรเดียวกัน

ตัวอย่าง B=100,P=110,F=5: ผู้ว่าจ้างจ่าย115 วิญญาณได้15คะแนนพิเศษ ส่วนราคาสินค้าหลังหักส่วนแบ่งเหลือ100 ไม่เรียกเก็บ125

## ข้อเท็จจริงการทำงาน

Serverเก็บคำตอบและเวลาเริ่มจริง บังคับรอสลับ5.2วินาที ปฏิเสธเวลาเริ่มปลอม ไม่ส่ง seed/เฉลย/base/ความจริงสินค้าใน DTO งาน เงื่อนไขสินค้าเก็บเป็น private snapshot และสินค้าส่งมอบมี ID/ความจริงใหม่แบบ seeded ตามระบบเดิม ภายในเกมเดียวกัน reconnect และเปิด/ปิดหน้าวิญญาณไม่เริ่มนาฬิกาใหม่ การบันทึกข้าม server restart ยังเหมือนระบบเดิม ไม่ใช่คุณสมบัติใหม่ของงานนี้

## งานบาลานซ์ที่ยังต้องเก็บ

- เวลา/การกระจายในการชนะมินิเกมและตามหาของ จำนวนช่วงที่ผู้ว่าจ้างรอ และความถี่ที่แพ้ครบ3ช่อง
- อัตราสำเร็จแยกชนิดสินค้า จำนวนงาน จำนวนวิญญาณ และขนาด catalog
- ราคาซื้อ+ค่าจ้างเทียบช่องทางปกติ แหล่งเงินของส่วนต่าง และรายได้/คะแนนหลังตายจริง
- แรงจูงใจตั้งใจตายหรือทำสัญญาอุ้มเพื่อน ผลการผ่าน functional tests ไม่ใช่หลักฐานว่า balanced
