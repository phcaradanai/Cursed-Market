### Component กลางสำหรับรูปพ่อค้า

`MerchantEventPortrait` ใช้สัดส่วนภาพ idle ของพ่อค้าทั้ง 8 จาก `merchant-portrait-frames.ts` โดยเทียบความสูงส่วนที่มองเห็นและฐานภาพ พร้อมจุดกึ่งกลางใบหน้ารายตัว ภาพไม่ถูกยืดและไม่มีกรอบพื้นหลัง E109 ใช้ component นี้แล้ว; event อื่นต้องนำไปใช้เมื่อพัฒนาหน้าเหล่านั้น

ตรวจ component จริงทั้ง 8 ในกรอบเดียวกัน: ความสูงส่วนที่มองเห็นประมาณ 250px ต่างกันน้อยกว่า 0.01px ฐานต่างจากแนวอ้างอิงไม่เกิน 0.01px [ภาพเปรียบเทียบ](merchant-portrait-comparison.png) เป็นหน้าตรวจชั่วคราว ไม่ใช่หน้าเกมจริง ใช้เฉพาะภาพ idle ยังไม่ได้ปรับภาพอารมณ์อื่น

## ผลตรวจฉบับสุดท้าย

### แก้ navigation หลังผู้ใช้ทดสอบ

E109 ใช้ GameDialog แบบ non-modal แล้ว จึงไม่ทำให้ dropdown ข้อมูลตัวอย่างหรือ dock กลายเป็น inert เปิดเมนูใดอยู่ให้ EventModal แสดงเป็น pill ชั่วคราว เมื่อปิดเมนูกลับเหตุการณ์เดิมถ้ายังไม่เคยกดซ่อนเอง ไม่ส่ง accept/decline หรือรีเซ็ตเวลา การตรวจ/ซื้อที่ต้องตอบเหตุการณ์ก่อนยังคงกฎ engine เดิม

Browser regression ผ่านครบ6เมนู (กระเป๋า/สถานะ/ตลาดมืด/บันทึก/กติกา/ตั้งค่า) เปิดแล้วเหตุการณ์ซ่อน ปุ่มเมนูเดิมปิดและคืนเหตุการณ์ได้ เปลี่ยน dropdown ไป rules แล้วกลับ event-blood-pact ได้จริง ชีวิตยัง4→2ตาม preview; TypeScript client ผ่าน นี่แก้ runtime และ preview ของ E109 ไม่เปลี่ยน event ชนิดอื่นเป็น non-modal โดยอัตโนมัติ

### แก้ภาพพ่อค้าที่ไม่ทะลุกรอบหลังผู้ใช้ตรวจภาพ
