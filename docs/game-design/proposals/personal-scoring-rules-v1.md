# Personal scoring v1 — สเปกทดลองพร้อมทบทวน

สถานะ **PROPOSAL / ยังไม่อนุมัติ / ยังไม่เปลี่ยนเกม**. หน่วยที่ผู้ใช้ยืนยันแล้วอยู่ `../personal-scoring-direction.json`. ตัวเลขเครื่องอ่านอยู่ `personal-scoring-weights-v1.json`. ทิศทาง: ทุกคนได้ผลงานหลายระบบ แยกจำนวนขายกับเครดิตขาย และความไว้ใจที่ได้รับสะสม ไม่ใช้กำไรสุทธิหรือtrustคงเหลือแทน

## ทางเลือกและเหตุผล

ผู้ใช้เลือก additive personal contributions แทนข้อเสนอbest-path-onlyที่ยังไม่เคยอนุมัติ จึงไม่ถามโครงสร้างซ้ำ. การขายแบบกำไรสุทธิถูกแทนด้วยสองหน่วยที่ผู้ใช้เลือกแล้ว. ข้อเสนอใหม่นี้คงมูลค่าทรัพย์สินเดิม แต่เพิ่มคะแนนผลงานทุกคนเป็นรายการแยก พร้อมเพดานต่อรายการเพื่อจำกัดการสะสมคะแนนจากกิจกรรมซ้ำ. ทางเลือกให้ทุกเครดิตขายเป็น1คะแนนโดยตรงจะทำยอดขายวนหนักกว่าเงิน/ของตอนจบ จึงเสนอ10เครดิตขาย=1คะแนนแทน ทั้งหมดรออนุมัติตัวเลข

## สูตร

A = คะแนนเงินในกระเป๋า+คลังและของตามสูตรเดิม (ปลอม/คำสาป/ตราประเมิน/rarityเดิม). P = ผลรวมคะแนนผลงานที่ผ่านสิทธิ์ของแต่ละรายการด้านล่าง. M = B10/D10ตามกฎเดิม. G = คะแนนวิญญาณที่จ่ายงานสำเร็จแล้วตามกฎ1เครดิต=1คะแนน

`score = floor((A + P) × (100 + M) / 100) + G`

ข้อเสนอ **ขยายผล B10/D10 ให้คูณคะแนนผลงานคนเป็นด้วย** แล้วบวกวิญญาณหลังตัวคูณเหมือนเดิม. สูตรรุ่นเก่าไม่เปลี่ยน. ไม่คูณโบนัสวิญญาณซ้ำ

## นิยามปิดดีลและกันปั๊ม

- ของต้นฉบับใช้immutable origin ID. รับคืน/ฝากถอน/ปล่อยค้ำ/ขโมย/ให้/แลก/ทำสำเนาไม่สร้างoriginใหม่. สำเนาเก็บrawกิจกรรมได้ แต่ไม่ให้คะแนนซื้อ/ขาย/ตรวจ/ตีราคา/rarityชุดนี้; คุณค่าทรัพย์สินและeffectสำเนาเดิมยังคงอยู่
- ซื้อคิดครั้งเดียวต่อผู้ซื้อ+originตลอดเกม. ขายคิดครั้งเดียวต่อผู้ขาย+originตลอดเกม และนับเมื่อส่งของ/เงินเสร็จ ราคาบวกเท่านั้น. การขายวนแสดงrawทุกครั้ง แต่ไม่มีแต้มเพิ่มให้ผู้ขายเดิมจากoriginเดิม. การส่งต่อให้ผู้ขายรายใหม่มีสิทธิ์ครั้งเดียวต่อราย จึงยังต้องดูcollusionระหว่าง2–4คนตอนทดลอง
- แหล่งขาย: PvPของในกระเป๋า,ตลาดมืด และขายของNPCให้ผู้อื่นสำเร็จ. ของNPCที่ผู้ประเมินซื้อเองไม่นับว่าตนขายให้ตนเอง. ผู้ประเมินปิดดีลให้ผู้อื่นใช้ราคาปิดเต็มเป็นยอดขายเครดิต แม้เงินเข้ากระเป๋าจะเป็นค่านายหน้าเท่านั้น; ค่านายหน้าไม่เพิ่มยอดขายเครดิตซ้ำ. Auctionนับซื้อเฉพาะผู้ชนะที่fund/รับของแล้ว ผู้ยื่นbidแพ้ไม่มีแต้ม และการยึดของเข้าประมูลของระบบไม่ทำให้เจ้าของเก่ากลายเป็นผู้ขายสำเร็จ
- Barter/ของให้/เครดิต0: แสดงรายการได้ แต่ไม่ให้แต้มซื้อขายชุดนี้ เพราะไม่มีราคาซื้อขายเงินจริงที่ยืนยัน. Refund/rebate/ของคืนจากยกเลิกไม่เป็นยอดขายเพิ่ม. Traceหลายแถวจากธุรกรรมเดียวใช้transaction identityเดียว ไม่รวมซ้ำ
- trustเริ่มต้นที่ให้ตอนสร้างเกมไม่เป็นผลงานที่ได้รับจากการเล่น. บันทึกactual positive mutationแต่ละแหล่งหลังclamp แม้คำสั่งเดียวมีทั้งบวกและลบ. ลดภายหลังไม่หักยอดสะสม. สำหรับสิทธิ์คะแนน trustจากtuple `(playerId, originId, merchantId)` เดียวกันให้ครั้งเดียวทั้งเกม; คนละoriginกับmerchantเดิมยังนับได้ และoriginเดิมที่เกิดgainจริงกับอีกmerchantใช้คนละtuple; event/สัญญาใช้unique offer/contract identity ไม่ใช่แค่ชื่อข้อความ. ยอดrawจริงและยอดeligibleต้องแสดงแยกกัน
- ตรวจนับเฉพาะactionตรวจที่เปิดfacetใหม่ ไม่ให้แต้มจากเปิดtooltip ดูของที่รู้อยู่แล้ว รับความรู้จากคนอื่น หรือเดาคำตอบซ้ำ. ตีราคาใช้ข้อเสนอแรก ไม่ให้ลองราคาจนเข้าช่วงแล้วนับเป็นความแม่น. ความจริงใช้หลังจบเกมเท่านั้น ไม่เปิดระหว่างเล่น
- NPCสัญญานับunique contract IDเมื่อfulfilled. รับคำสัญญาแล้วตาย/หมดอายุไม่ให้แต้ม. เกมคลิกตอบevent/omenทั่วๆไปไม่ให้แต้มเพียงเพราะกด แต่ผลงานที่เกิดจริงเช่นขาย trust HP หรือรอดถูกนับตามหน่วยของมัน
- เงินกู้: อยู่ข้ามหนึ่งencounterเต็มระหว่างfundกับชำระครบ, ผู้กู้/ผู้ให้กู้คนละคน, ใช้originค้ำเดียวได้หนึ่งครั้งสำหรับคู่นั้น. คะแนนให้ทั้งผู้กู้และผู้ให้กู้ที่ทำสำเร็จคนละ5ภายใต้cap20 ไม่ใช้ยอดprincipalเป็นแต้ม. กู้คืนทันทีในjourneyทดสอบก่อนหน้านับrawสำเร็จ แต่ไม่มีสิทธิ์คะแนนนี้. Foreclosure/ยกเลิก/ผู้กู้ตายก่อนคืนครบไม่มีแต้มเงินกู้คืนครบ
- การขโมยของใช้originต่อผู้เล่นหนึ่งครั้ง; ล้วงเงินใช้ผู้ถูกขโมย+encounterหนึ่งครั้งเมื่อโอนเงินจริงบวก. การถูกขโมย/ส่งมือ/แพ้/เสมอไม่ให้แต้มเพียงเพราะเล่นดวล. ไม่เปลี่ยนกฎบังคับดวล/timeout
- counterผลงานจากการกระทำคนเป็นหยุดเพิ่มหลังdeath ยกเว้นงานวิญญาณตามกฎที่ยืนยัน. **ข้อเสนอrarityเป็นการประเมินของที่ถือจบสำหรับทุกคนรวมผู้ตาย** ใช้custodyหลังCollectorsettleหนี้เช่นเดียวกับฐานทรัพย์สิน ไม่freezeของตอนตายหรือให้ศูนย์อัตโนมัติ. ดังนั้นestate/collateralที่settleภายหลังอาจเปลี่ยนส่วนทรัพย์สิน/rarityของผู้ตายได้ ไม่ใช่การให้ผู้ตายทำactionเก็บผลงานเพิ่ม. ข้อนี้เป็นกติกาทดลองที่ต้องอนุมัติพร้อมชุดคะแนน ไม่ได้อ้างว่าผู้ใช้ยืนยันแล้ว. ไม่คืนชีพ ไม่แชร์ชัยชนะกับผู้ว่าจ้าง ไม่เพิ่มแต้มจากการเริ่มหรือชนะมินิเกม. ทรัพย์สินและsettlementตอนCollectorยังตามกฎเดิม; ไม่เสนอfreezeฐานทรัพย์สินใหม่โดยปริยาย
