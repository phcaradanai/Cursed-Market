# Strategic paths — หลายเส้นทางสู่ชัยชนะ

สถานะ: ผู้ใช้ยืนยันว่าต้องการเกมวางแผนที่เลือกเส้นทางเองและชนะได้หลายทาง คล้าย Civilization; รายละเอียดต่อไปนี้เป็นข้อเสนอ ยังไม่ใช่เงื่อนไขชนะที่ลง runtime

## หลักออกแบบ

- ผู้เล่นเลือกจากการลงทุนและการกระทำจริง ไม่ล็อกคลาสตั้งแต่ต้น; ผสมสายหรือเปลี่ยนแผนได้โดยมีต้นทุนค่าเสียโอกาส
- ความสำเร็จต้องมีหลายเส้นทางที่แข่งขันกันได้ ไม่ใช่สะสมเงินก้อนใหญ่แล้วรับโบนัสทุกสายพร้อมกัน
- สายหลักใช้เพื่อวางแผนระยะยาว ส่วน tactical actions เช่น ขโมย ชำระคำสาป แลกเปลี่ยน และเลือก event ช่วยเปลี่ยนจังหวะเกม
- แต่ละสายต้องมี progress ที่เข้าใจได้ คู่แข่งมีเวลาตอบโต้ โดยไม่เปิดความแท้/คำสาป/ของในช่องลับ
- ยืนยัน 2026-10-28: ทุกสายตัดสินผู้ชนะพร้อมกันตอนจบเกมเมื่อ Collector มา การบรรลุเป้าหมายก่อนเวลาไม่ทำให้ชนะทันที

## สายที่เสนอจากระบบที่มี

| สาย | สิ่งที่ผู้เล่นสร้าง | ลงทุน/ข้อแลกเปลี่ยน | คู่แข่งตอบโต้ได้อย่างไร | แหล่งระบบ |
|---|---|---|---|---|
| การค้า | กำไรสุทธิจากดีลหลายคู่ค้า | ต้องใช้เงินหมุน/ตรวจ/รับความเสี่ยง | แย่งสินค้า ประมูล แข่งข้อเสนอ | L04–L08, L20 |
| นักสะสม | ชุดสะสมตาม rarity/ชนิด/ที่มาที่กำหนด | เงินจม สินค้าใช้แล้วหายหรือขายไม่ได้ระหว่างสะสม | แย่งเป้าหมาย ต่อรองราคาของหายาก | L09, L21, L29, L30 |
| สัมพันธ์พ่อค้า | ความไว้ใจหลายราย/พันธะและสกิล | เสียโอกาสเลือกดีลอื่น ใช้เวลาและรักษาสัญญา | แข่ง stock/เส้นทางและการเข้าถึงข้อเสนอ | L10–L12, L22 |
| การเงิน | เงินต้นอายุครบ/พอร์ตเงินกู้ที่ชำระจริง | สภาพคล่องต่ำ เสี่ยงผู้กู้และหลักประกัน | แข่งเงื่อนไขเงินกู้/ลงทุนตลาดระหว่างเงินถูกพัก | L16–L18 |
| เอาตัวรอด/เสี่ยงอย่างมีแผน | จัดการชีวิต พลัง สถานะ และ omen เพื่อบรรลุเป้าระยะยาว | ใช้ของ/เงินเพื่อรอดแทนลงทุนทันที | กดดันจังหวะตลาดและทรัพยากร | L23–L28 |

ชื่อสายไม่จำเป็นต้องเป็นชื่อ achievement หรือหน้าจอเลือกคลาส ตัวอย่างนักสะสมจะถือว่าเป็นสายชนะจริงได้ต่อเมื่อเป้าหมาย/รางวัลทำให้แข่งขันกับสายอื่นได้จากผลทดสอบ ไม่ใช่แค่เปลี่ยนคำอธิบายคะแนนรวม

## ป้องกันการชนะทางลัด

- ห้ามนับการซื้อขายวนกับผู้เล่นเดิมเป็นการค้าใหม่ไม่จำกัด; แยกยอดซื้อขาย กำไรสุทธิ และคู่ค้าจริง
- สำเนา/ของยืม/ของค้ำไม่ควรถูกนับเป็นชุดสะสมซ้ำเจ้าของ; ตัดสินตาม custody และนิยามที่ยืนยันก่อนใช้
- คะแนนจากเงินต้น/ดอกเบี้ยต้องไม่ทำเงินก้อนเดียวรับรางวัลหลายสายจนเหนือการลงทุนอื่นโดยอัตโนมัติ
- รางวัลวัดพลังชีวิตที่เสียสะสม ผู้เล่นตายได้ครั้งเดียว ไม่ใช่รางวัลตายบ่อย ต้องประเมิน loop รักษาแล้วเสียพลังชีวิตซ้ำ
- ไม่มีเส้นทางใดแก้ความเสี่ยงของทุกระบบได้ด้วยสินค้าเดียว; ตรวจรายการสินค้าที่เชื่อมกว้างเกินไปใน relation

## งานพัฒนาต่อ STRAT-01

1. รูปแบบจบเกมยืนยันแล้ว: ตัดสินพร้อมกันตอน Collector; ขั้นต่อไปนิยามเป้าหมาย/โบนัสของแต่ละสายกับรางวัลรอง
2. ทำตาราง progress/cost/target/counter ของแต่ละสายผูก stable entity IDs
3. เลือกสินค้าใหม่ให้สนับสนุนหลายแนวทางทั้งหลัก/รอง โดยยังคุม type/palette ของพ่อค้า
4. เก็บ baseline แยก policy ต่อสายและแบบผสม; seed/config เท่ากัน มีรายงานโอกาสชนะ/จังหวะสำเร็จ/ความสามารถพลิกเกม
5. ทดลองเป้าหมายและน้ำหนักในกลุ่มเล็กก่อนกระจายครบ 56; UI status แสดง progress แบบ comic โดยใช้ component เดิม

ห้ามแต่งค่า threshold หรือจำนวนคะแนนเป็นกฎอนุมัติ งาน RULE-01 เงินฝากที่กำลังทำเป็นพื้นฐานสายการเงิน ไม่ใช่ระบบชัยชนะหลายสายที่เสร็จแล้ว

## การตัดสินใจที่ยืนยัน

2026-10-28 ผู้ใช้เลือก “ตัดสินพร้อมกันตอนจบ” จากคำถามเรื่องจบเมื่อ Collector เทียบกับครบเป้าแล้วชนะทันที การยืนยันนี้ไม่รวมจำนวนคะแนน threshold แต่ละสาย หรือกฎเสมอ และยังไม่เปลี่ยน runtime ให้มีเงื่อนไขชัยชนะหลายสาย
