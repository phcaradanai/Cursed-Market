# Language switch (Thai / English)

The table UI can switch between Thai (default) and English from the masthead button (`EN` / `ไทย`).
The choice is saved in `localStorage` under `cursed-market:lang`, and `<html lang>` follows it.

## How it works

- `src/appraisal-client/i18n.ts`: `t(text, vars?)` returns the English entry in English mode, or the Thai text itself.
  The Thai source string is the lookup key, so Thai never changes and a missing English entry falls back to Thai.
  Placeholders such as `{n}` are filled in either language.
- `src/appraisal-client/i18n-en.ts`: merges the English tables in `en/model.ts` and `en/ui.ts`.
- `src/appraisal-client/i18n-content.ts`: English game text keyed by catalog id (items, statuses, merchants, events, omens, passives).
- `src/appraisal-client/catalog-text.ts`: accessors (`itemName`, `statusDescription`, `eventText`, ...) that pick Thai or English.
- The client composes item benefit and drawback text itself (`possibleBenefitText`, `possibleDrawbackText`), so no server Thai reaches the screen.

## Adding or changing a UI string

1. Write the Thai text inside `t('...')`, with `{name}` placeholders for dynamic parts.
2. Add the same key to `en/ui.ts` (or `en/model.ts`) with the same placeholders.
3. `tests/appraisal-i18n.test.ts` fails if a key is missing or an English value still contains Thai or loses a placeholder.

## Known gap

Engine notes (`notes` in the seat view, the "recent results" panel and the first line of some toast cards) are written
in Thai on the server. They stay Thai in English mode. The fix is to have the engine emit structured note keys
with parameters and translate them on the client, which changes the audit state shape, so it is a separate change.
