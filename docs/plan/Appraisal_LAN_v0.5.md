# เล่น Survival + Collector v0.5 บน LAN

รุ่นกติกาใหม่: **http://192.168.10.150:3107**. ใช้เครือข่ายเดียวกับ server เปิด URL เดียวกันในอุปกรณ์ของผู้เล่น 2–4 คน แล้วสร้าง/เข้าด้วยรหัสห้อง

เจ้าของห้องเลือกจับเวลา/ไม่จับเวลา ตั้ง4ช่วงเป็นจำนวนเต็ม1–900วินาทีแล้วบันทึกก่อนทุกคนพร้อม หากเปลี่ยนค่าจริงทุกคนต้องพร้อมอีกครั้ง ค่าเริ่มต้น30/90/45/4วินาทีอยู่ต่อใน rematch โหมดไม่จับเวลารอผู้ที่ยังมีชีวิตตอบ; ผู้ตายไม่ต้องกดไปต่อ ผู้มีชีวิตที่หลุดต้องกลับมา

พลังไม่ใช่ชีวิต: พลัง0ยังเลือกประตูและรับดีลฟื้นได้ แต่การกระทำที่ใช้พลังต้องมีพอ ชีวิต0เป็นผู้ชมจนจบ run ไม่มีการฟื้นช่วงหน้า เริ่มชีวิต6;ท้ายแต่ละ encounter เสียชีวิต1 ฟื้นจากอาหาร/ยาหรือดีลพ่อค้าได้ ไม่มีจบตายตัวที่สามencounter

เมื่อทุกคนตาย Collector รับของที่เหลือและรวมเครดิตกับผลคะแนนจากสถานะ ตารางผลแสดงมูลค่ารวม เครดิต เปอร์เซ็นต์ปรับคะแนน และคะแนนสุดท้าย เปิดรายละเอียดดูของแท้/ปลอม/คำสาปของแต่ละชิ้นได้ ดาวน์โหลด audit **ก่อน rematch หรือหยุด server** ผู้ตายก่อนยังได้รับคะแนนจากของและเครดิตที่เหลือ ไม่ได้0อัตโนมัติ

Reload แท็บเดิมกลับที่นั่งด้วย session token; เปิดแท็บใหม่เป็นคนใหม่ ผู้ชมยังดูข้อมูลสาธารณะของเพื่อนได้ ไม่เห็นผลตรวจส่วนตัวหรือ RNG ในอนาคต

```sh
npm ci
npm run build
PORT=3107 HOST=0.0.0.0 npm start
```

PORTนี้เป็น snapshot ของ session; ถ้าถูกใช้อยู่ให้ใช้พอร์ตว่างใหม่ ห้าม restart/killห้องที่กำลังเล่น ห้องเก็บใน memory ข้อมูลที่ยังไม่ดาวน์โหลดหายเมื่อหยุดprocess Default PORT ยังคง3103; ทุกห้องใหม่ใช้ Survival โดยตรง ไม่ต้องตั้ง APPRAISAL_RULES พอร์ต3100–3105เดิมเก็บไว้

```sh
npm run replay -- path/to/downloaded-v5.json
npm run --silent playtest:report -- path/to/downloaded-v5.json > /tmp/survival-session-report.json
```

Replay/reportรองรับ schema5ใหม่และ4เดิม ดู [กติกาและค่าทดลอง](Survival_Collector_v0.5.md), [หลักฐานเทคนิค](../validation/survival-v0.5.md) และ [human playtest](../playtests/appraisal-v0.5.md). ไม่มี public hosting; IPอาจเปลี่ยนเมื่อเครือข่ายเปลี่ยน การตรวจ socket จากเครื่องserverไม่ยืนยัน reachability ของทุกอุปกรณ์


เกมหลักเป็น Survival (v0.5) ทุกห้องใหม่ใช้กติกาเอาชีวิตรอด ไม่มีตัวเลือกโหมดในล็อบบี้ ไม่ต้องตั้ง `APPRAISAL_RULES` โหมดพัฒนาใช้ `npm run dev` (http://localhost:5174)
