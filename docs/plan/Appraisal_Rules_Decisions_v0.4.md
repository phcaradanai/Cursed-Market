# v0.4 — Decision ledger สำหรับทดลอง

2026-10-13 — M0 ของ [แผนส่งมอบ](Card_Appraisers_Delivery_v0.4.md) ข้อกำหนดผู้ใช้มาจาก appraisal draft, RNG catalog และ Dark Market; ตัวเลขและสูตรด้านล่างเป็นค่าทดลองของผู้ช่วย ไม่ใช่ balance ที่ผู้ใช้ยืนยันหรือผ่าน human playtest

## ข้อกำหนดผู้ใช้ที่ไม่เปลี่ยน

เลือกประตูพบ NPC ต่างมิติ, ประเมิน/ซื้อ/รับเงื่อนไข, inventory มีผลดีและผลเสีย, พลังแยกจาก credit, ต่อรองและชมของเพื่อน, การกดราคา NPC มีผลเสียแต่ P2P ไม่มีบทลงโทษนี้, ตาย/พลังหมดพักเฉพาะ encounter แล้วกลับมา, 50 events/20 statuses ทำงานจริง, Dark Market สุ่มก่อน encounter และรับซื้อจน encounter จบ โดยชนิดที่เคยขายยังมีโอกาสเป็น demand

## ค่าทดลองและ phase

| เรื่อง | ค่าตั้งต้น / คำตัดสิน |
| --- | --- |
| Run | 3 encounters; เริ่มใหม่รีเซ็ตทรัพยากร สถานะ และ RNG history |
| ผู้เล่น | 2–4 คน; แต่ละคนเลือกหนึ่งใน 3 ประตูของตนและประเมิน NPC พร้อมกัน |

| Action | ตรวจปกติ 1 พลัง, ประเมิน/ต่อรอง 1, ซื้อ NPC 1, เปิดใช้สินค้า 1; เลือกประตู/ปฏิเสธ/จบช่วง/P2P/Dark Market 0; modifiers อาจเปลี่ยนต้นทุน ต่ำสุด 0 |
| Limits | ตรวจได้ 2 ครั้ง/encounter, ประเมินแต่ละชิ้นครั้งเดียว, ต่อรอง NPC อีก 1 ครั้งรวม/encounter; B10/D08 เปลี่ยนโควตาต่อรองเท่านั้น ไม่ยกเลิกต้นทุน |

| NPC | Orc, Vampire, Autometa, Alien, Dark One และสัตว์นำทาง; ความไวต่อราคา เงื่อนไขและ pool ข้อเสนอแตกต่างกัน |
| Stock | สองชิ้นต่อ NPC; base สุ่มอยู่ในช่วงราคาอ้างอิงของชนิดสินค้า; ความแท้/คำสาปแยกสุ่ม เก็บ server เท่านั้น |

ทุกคนจบหรือพักใน APPRAISAL จึงเปิด TRADE; ทุกคนจบหรือพักใน TRADE จึง settlement และ REVEAL ผู้พักทั้งหมดเดินผ่าน phase อัตโนมัติ ไม่รอคำสั่งที่ส่งไม่ได้ เวลาหมด/หลุดให้เลือก pass/decline/done ตาม phase ไม่รับดีลเสี่ยงแทนผู้เล่น

ค่าทดลองเริ่มต้นของ room controller จาก M3: PORTALS30วินาที, APPRAISAL90วินาที, TRADE45วินาที, REVEAL4วินาที คำขอเพิ่มวันที่2026-10-14ให้เจ้าของตั้งจับเวลา/ไม่จับเวลาและเวลา4ช่วงเป็นจำนวนเต็ม1–900วินาทีใน lobby ได้ การเปลี่ยนค่าจริงล้าง readiness, ล็อกระหว่างrun และคงค่าในresume/rematch โหมดจับเวลา Deadline ผูกกับ phase ไม่เลื่อนทุกครั้งที่ส่ง action; เมื่อหมดให้ resolve defaults และ advance เมื่อครบ โหมดไม่จับเวลามี deadline=null รอผู้ที่ยังต้องตอบ รวมผู้หลุดกลับมา และทุกseatยืนยันREVEAL ไม่มีtimeoutอัตโนมัติ ดู [หลักฐาน](../validation/appraisal-timers-v0.4.md)

## ราคาและปฏิกิริยา NPC

ชนิดสินค้ามี reference anchor และช่วง [70%,130%] ของ anchor; base จริงสุ่มภายในช่วง ไม่สร้างช่วงโดยเอา base เป็นค่ากลางที่คำนวณย้อนกลับได้ การตรวจราคาแคบช่วงแต่ไม่เปิดเลขจริง เว้นแต่ B01 ทำงาน; D02 กัน B01 แต่ไม่ลบข้อมูลที่รู้แล้ว การตรวจความแท้และผลสินค้าเป็นความจริงที่ server รับรอง ไม่ใช่คำกล่าวอ้าง NPC

ประเมินไม่บังคับซื้อ NPC ตอบรับค่าที่เสนอเมื่อไม่ต่ำกว่าราคา reservation ของชิ้นนั้น ซึ่งสุ่มคงที่และซ่อนไว้ตามพฤติกรรม NPC: Orc45–80%, Vampire35–65%, Autometa70–90%, Alien40–85%, Dark One25–70%, Beast35–60% ของ base ปัดขึ้น จำกัดอย่างน้อย1และไม่เกินราคาหน้าร้าน ถ้าปฏิเสธให้ซื้อราคาหน้าร้านหรือใช้สิทธิ์ต่อรองเพิ่ม ไม่แปลงเลขประเมิน0เป็นราคาซื้อฟรี UI แยกราคาอ้างอิง การตอบรับ และราคาซื้อจริง

ราคาที่จ่ายคือ quote ที่ NPC ยอมรับ บวก/ลบเงื่อนไขที่แสดงก่อนซื้อ การซื้อชุดใช้ B03/D06 ครั้งเดียวต่อคำสั่ง ซื้อราคาหน้าร้านได้โดยไม่ประเมิน แต่ไม่มีโบนัสความแม่นยำ Reservation ไม่ใช่การตรวจจับและไม่เปลี่ยนตัวอย่าง20% ตัวเลขนี้เพิ่มหลังตรวจ kernel พบว่าการยอมรับทุกเลขทำให้กด0แล้วได้ของฟรี เป็นค่าทดลองเพิ่มเติมของผู้ช่วย

ความเสี่ยงจับผิด = clamp(0.4 × max(0, 1 − ราคาเสนอ/base) × sensitivity + modifiers, 0, 1) ใช้ sensitivity Orc=1, Vampire=.75, Autometa=.5, Alien=1.25, Dark One=1.5, Beast=.6 ตัวอย่าง Orc base20 / เสนอ10 / ไม่มีสถานะ =20% modifiers ของสถานะเป็น percentage points ตามคลัง ถ้าไม่มีการกดราคาไม่ใช้ตรานักโกงสร้างความเสี่ยงเอง; งานเกียรติ E02 ที่ผิดช่วงมีความเสี่ยงเพิ่มตามเงื่อนไขของงาน

NPC ที่จับผู้เล่นได้แล้วปิดสิทธิ์ประเมิน/ต่อรองใหม่ของผู้เล่นนั้นใน encounter นี้ แต่ยังเลือกซื้อราคาที่เปิดไว้หรือปฏิเสธได้ ไม่ให้การจับผิดครั้งถัดไปเลี่ยงผลเสียเพราะ slot ผลต่อเนื่องใช้ไปแล้ว ใช้สถานะเดิมของ appraisal ก่อนรับสถานะรางวัลใหม่ เพื่อไม่ใช้ B04 ที่เพิ่งได้ทิ้งใน action เดียวกัน

UI ที่ยังไม่รู้ base แสดงช่วงความเสี่ยงจากช่วงราคา ไม่ส่งเลขความเสี่ยงที่คำนวณจาก base จริงให้ client เมื่อรู้ base แล้วแสดงเลขแน่นอนได้ สุ่มตรวจจับด้วย label คงที่ของ encounter/seat/สินค้า การต่อรองซ้ำไม่เปลี่ยนเลขสุ่มที่ใช้ แต่ยังเสียพลังและมีโควตา

เมื่อถูกจับ เลือกผลต่อเนื่องหนึ่งรายการ E48/E49/E50 ตาม NPC และเงื่อนไข ไม่ตรวจจับใหม่เพื่อเลือกผลเสียอีก E48 เสีย2credit หรือของที่เลือกหนึ่งชิ้น; ถ้าไม่มีทั้งสองใช้เสียพลังไม่เกิน2 E49 จ่าย2creditหรือรับD08 เมื่อยังมี encounter ถัดไป E50 ใช้เฉพาะ Dark One ที่ผู้เล่นยอมรับสัญญาความเสี่ยงตายก่อนยืนยัน มีทางเลือกสละของถอนสัญญา; B08 แทนตายด้วยเสีย2พลัง

ผล NPC ไม่ถูกเรียกจาก P2P กรณีรับคำสาป/ของปลอมจากผู้เล่นยังเกิดผลสินค้าได้ตามความจริงของของนั้น

## Inventory, สถานะ และ RNG

ใช้ชนิดสินค้าให้ครอบคลุมเงื่อนไขคลัง: mirror/orb/key/mask/potion/battery/amulet/blade/scanner/food เปิดใช้ได้ครั้งเดียวต่อชิ้นต่อ encounter; consumable ถูกนำออกจริง ผลที่ติดผู้เล่นยังอยู่หลังขายตามอายุ ไม่ย้อนต้นทุน D09 ล็อกชิ้นที่ระบุ ห้ามขาย/แลก; การซื้อชุดและโอนของตรวจทั้งหมดก่อนแก้ state

ใช้ timing/charges/การได้ซ้ำของ B01–B10 และ D01–D10 ตาม [catalog](RNG_Content_v0.4.md) ชนิดเดียวกันไม่บวกทับ ใช้เวลาหรือ charges สูงกว่า เงื่อนไขโล่ใช้เมื่อเหตุจริงเกิดเท่านั้น สถานะที่ไม่มีเป้าหมายหรือไม่มี encounter ถัดไปไม่ถูกเสนอ E01–E47 เป็นข้อเสนอปฏิเสธได้; E48–E50 เป็นผลจากความเสี่ยงที่ยืนยันแล้วจึงต้อง resolve ไม่ให้ decline เพื่อลบโทษ

ไม่เกินสอง event ข้อเสนอ + หนึ่ง event ผลต่อเนื่องต่อ seat/encounter: slot ประตู, slot ประเมิน และ slot inventory/trade ใช้ได้ไม่เกินสอง slot แรกที่เข้าเงื่อนไข ไม่ซ้ำ event ID ต่อ seat/run เว้นแต่รายการที่เข้าเงื่อนไขใช้หมด จึงเริ่มกลุ่มใหม่ สุ่มจาก eligible set เท่านั้น ตัวเลือก/เป้าหมาย/ข้อเสนอสำรองถูกล็อกตอนเสนอ event ไม่แก้จาก retry หรือการแลกของภายหลัง

## การขอดูและซื้อข้ามร้าน

เจ้าของต้องประกาศ share-stock/share-item ก่อนให้คนอื่นขอดู เผยคำกล่าวอ้าง ช่วงราคา ราคาอ้างอิงจาก appraisal และเงื่อนไขซื้อที่ต้องยอมรับ; ไม่เผย private inspection โดยอัตโนมัติ E45 เปิดข้อมูลเพียงข้อที่ผู้เล่นเลือกและรับรองโดย server

P2P เสนอ credit และ/หรือของแลกให้เจ้าของตอบรับ โอนเงินและของพร้อมกัน once-only ทั้งสองต้องยัง active และเป็นเจ้าของของจริง ของล็อก/ขายไปแล้ว/เงินไม่พอทำให้ทั้งรายการไม่เกิดผล

เมื่อของ/รายการไม่พร้อมหรือฝ่ายใดพัก/จบช่วง ข้อเสนอค้างที่เกี่ยวข้องเปลี่ยนเป็น rejected ทันที ไม่ปล่อยให้ปุ่มรับซื้อของที่ขายไปแล้วค้างอยู่; retry ของการตอบรับเดิมไม่โอนซ้ำ Event response ต้องตรง offer key ปัจจุบันแม้ยังอยู่ encounter เดิม

ซื้อข้าม NPC stock ได้เฉพาะของที่ถูกประเมินแล้วและเจ้าของเปิดให้ซื้อ ยื่นข้อเสนอให้นักประเมินเดิมตอบรับ ผู้ซื้อจ่าย NPC ตามราคาประเมินและค่าตอบแทนนักประเมินตามข้อเสนอ พร้อมพลัง/เงื่อนไขซื้อ นักประเมินเดิมรับผิดชอบความเสี่ยง appraisal ของตนที่ resolve แล้ว ผู้ซื้อรับเงื่อนไขสินค้า/การซื้อที่แสดง ไม่มีการกดราคา NPC ใหม่โดยแฝงเป็น P2P หากรายการเปลี่ยนหรือมีคนซื้อก่อน ข้อเสนอหมดผล ไม่คิดเงิน

## Dark Market และ economy

โอกาสเปิด50%; สุ่ม1–3ชนิดไม่ซ้ำจากสินค้าที่มีโอกาสเข้าถึงผ่านประตูของ run ทั้งหมด รวม encounter ที่ผ่านไป สุ่มราคา1.25–1.75เท่าของ reference anchor ไม่ขึ้นกับราคาที่ผู้เล่นกรอกหรือสินค้าที่เพิ่งขาย โควตาหนึ่งชิ้นต่อชนิดต่อผู้เล่น กันงบครบตาม quote × จำนวนสิทธิ์ทุก seat; ถ้างบไม่พอไม่เสนอคำรับซื้อเกินงบ

ราคา/โควตาคงที่จนจบ encounter ไม่มีเงื่อนไขรับซื้อความแท้/คำสาปพิเศษใน preset แรก; ตลาดรับชนิดที่ระบุจากผู้เป็นเจ้าของและนำชิ้นนั้นออกจากระบบ จ่ายเงินทันที transaction เดียวและลดงบ/โควตา ผู้พักดูได้แต่ขายไม่ได้ Quote ของ encounter เก่าหมดอายุเมื่อ settlement

เครดิตจาก NPC rewards/รับซื้อและตลาดมาจาก bank reserve จำกัด; ราคา/ค่าปรับที่จ่ายคืน reserve บันทึก ledger ทุก transfer การรับรางวัลครั้งเดิมซ้ำ/หมุนของที่ถูกใช้หรือขายออกแล้วไม่สร้างเงิน ตรวจยอด player credits + bank reserve จากบัญชีตั้งต้นทุก action

Reserve ตั้งต้น2000credit; กันงบตลาดและสิทธิ์รางวัล E43 แยกจากเงินที่จ่ายรางวัลอื่นได้ รางวัลเผยข้อมูล E19/E45 จ่ายเฉพาะข้อเท็จจริงที่ยังไม่เปิดสู่ตลาด ไม่จ่ายอีกเมื่อเจ้าของใหม่เผยข้อมูลเดิม D09 ห้ามขาย/แลกแต่ไม่ห้ามใช้ consumable; ของที่ถูกใช้หรือยึดออกจริงทำให้ lock ของชิ้นนั้นหาย โดยไม่ล้างสัญญาประเภทอื่น

## คะแนนและตัวอย่าง

คะแนน encounter = max(0, ความมั่งคั่งสุทธิท้ายช่วง − ต้นช่วง) + โบนัสความแม่นยำ โดย wealth = credit + มูลค่าของที่ถือ (base; ของปลอมใช้25%; คำสาปลดอีก25%, ปัดลง) โบนัส5ต่อชิ้นเมื่อ appraisal ห่าง base ไม่เกิน10% ตายให้ encounter นี้0; หมดพลังไม่ล้างผลที่ได้แล้ว คะแนน run คือผลรวมคะแนน encounter ไม่เพิ่ม inventory ซ้ำตอนจบ การตายไม่ย้อน settlement หรือแต้ม encounter ก่อนหน้า ไม่มีคะแนนถาวรข้าม run

| กรณี | ผลที่ต้องทดสอบ |
| --- | --- |
| Orc base20 / ราคา10 | โอกาสถูกจำได้20% ก่อน modifiers; ซื้อหรือปฏิเสธได้แยกจาก appraisal |
| พลังเหลือ1แล้วซื้อใช้1 | ซื้อสำเร็จครบก่อนพัก; ไม่ซื้อของใหม่หรือขายตลาดจน encounter ถัดไป |
| ตาย encounter2 หลังได้แต้ม encounter1 | encounter2=0; encounter1อยู่; encounter3กลับด้วยพลังขั้นต่ำก่อน D10/ผลสินค้า |
