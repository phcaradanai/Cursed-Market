# Cursed Market v0.4 — คลังสินค้า 30 ชนิด

2026-10-14 — ผู้ใช้กำหนดสินค้าขั้นต่ำ 30 ชิ้น ใช้เป็น **30 ชนิดที่แตกต่างกัน** ในคลัง สินค้าแต่ละชนิดมีชื่อ ราคาอ้างอิง ผลใช้งานและความเสี่ยงของตนเอง สุ่มพบผ่านพ่อค้า ประเมิน ซื้อ เปิดใช้ แลกกับผู้เล่น และขาย Dark Market ตามชนิดที่ตลาดต้องการได้ จำนวนนี้เป็นคลังทั้งเกม ไม่ได้บังคับให้เจอครบทุกชนิดใน run เดียว

ภาพร่วมตาม 10 หมวดเดิม รวม 10 item rasters +6 NPC rasters พร้อม provenance เดิม ชื่อและข้อมูลบนการ์ดแยกชนิดจริง ภาพไม่เปลี่ยนตามความแท้/คำสาปที่ซ่อนอยู่ ยังไม่ได้สร้างภาพใหม่แยก 30 ภาพ ตัวเลขและผลทั้งหมดเป็นการทดลอง balance

## การสุ่มและ compatibility

New runs ใช้ `catalogVersion:2` ใน saved config พ่อค้าแต่ละชนิดมีสินค้า 9 ชนิดจากหมวดที่พ่อค้าชอบเดิม ทุกชนิดอยู่ใน pool พ่อค้าอย่างน้อยหนึ่งกลุ่ม Dark Market เลือกจากชนิดที่เกิดใน seeded encounter stock จริง และไม่จงใจเล็ง inventory หรือประวัติขายของใคร แต่ละ stock ยังคง 2 ชิ้นต่อประตู ไม่เพิ่มความยาว encounter หรือจำนวน event/status

Audit v0.4 เดิมที่ไม่มี catalogVersion จะใช้ pool 10 ชนิดและลำดับสุ่มเดิมผ่าน exact-config restore โดยไม่ใส่ field ใหม่ลงในผลเก่า รองรับ catalogVersion:1 ด้วย ฟังก์ชัน replay และ report timing reconstruction ใช้ factory restore เดียวกัน ไม่แก้ baseline JSON เก่า

Family events E07/E31/E32/E33/E34/E35/E36/E38/E39 รับสมาชิกใหม่ในหมวดที่ตรงกัน การฟื้นพลัง/ปลดประตูจากการเปิดใช้ใช้หมวดเดียวกับของเดิม และแสดงผลจริงก่อนใช้ ผลเฉพาะ event ใช้ค่าที่ event ระบุ

Rollback ในช่วงผสมรุ่น: ใช้เซิร์ฟเวอร์เดิมพอร์ต3103 หรือเริ่ม run ด้วย catalogVersion:1; เก็บ audit ก่อนหยุด/เปลี่ยน process Audit รุ่น2 ต้องใช้ reader ที่รองรับคลัง30 ซึ่งส่งมอบพร้อมกัน ไม่เปิดไฟล์ใหม่ด้วย buildเก่าที่รู้เพียง10ชนิด
