# Cursed Market — First human playtest

สถานะ: ผู้ใช้รายงานหลังลองจริงว่าไม่สนุกและตัดสินใจซ้ำ ต่อมาขอเพิ่ม roguelike และ RNG ดู [หลักฐานและคำขอล่าสุด](2026-10-13-first-feedback.md) กับ [กติกาทดลอง v0.3](../plan/Roguelike_Run_v0.3.md) ยังไม่มีคะแนนรายคนหรือ audit จากคนจริงของ v0.3 ด้านล่างแยกคำอธิบายรุ่นปัจจุบันจาก protocol v0.1 ที่เก็บไว้อ้างอิง

ทดสอบคำถามเดียวก่อน: คนที่เพิ่งเล่นเข้าใจกติกาเร็วพอ และอยากเล่นอีกแมตช์ด้วยตนเองหรือไม่ หากไม่สนุก ให้หาเหตุผลจากการตัดสินใจและช่วงรอ ก่อนเพิ่มของหรือปรับภาพ

## เปิดเกมให้กลุ่ม

1. เครื่อง server รัน `npm run build` และ `npm start` หากยังไม่ได้เปิด server
2. ทุกเครื่องใช้ Wi-Fi/LAN เดียวกัน รุ่น v0.3 ที่เปิดสำหรับ session นี้อยู่ที่ `http://192.168.1.114:3102` เครื่อง server ใช้ `http://localhost:3102` ได้ หากเปิดใหม่ด้วย `npm start` ค่าเริ่มต้นคือพอร์ต 3100; ใช้ `PORT=3102 npm start` เพื่อเปิดที่พอร์ตเดิมเมื่อพอร์ตว่าง
3. คนหนึ่งสร้างห้อง คนอื่นใช้รหัสเดียวกัน ตั้งชื่อสั้นหรือรหัส P1–P4 จดว่าใครอยู่ seat ใด
4. เจ้าของห้องเลือก **ไม่ใช้ voice** สำหรับครั้งแรก ทุกคนกดพร้อมแล้วเริ่ม หลังคำอธิบายและคำถามความเข้าใจด้านล่าง
5. ดาวน์โหลดผลแมตช์หนึ่งไฟล์ต่อแมตช์ทันทีที่จบ **ก่อน rematch** ห้องและผลอยู่ใน memory; server restart ทำให้ห้องหาย

IP ของ server ตรวจใหม่ได้จาก network settings ของเครื่อง อย่าแจก `localhost` ให้เครื่องอื่น ใช้ URL ของ LAN ที่ยืนยันแล้วในวันทดสอบ

## คำอธิบาย retest v0.3

แต่ละ run มีสามตลาด ทุกคนเป็นผู้ขายหนึ่งครั้งต่อตลาด รวม 6/9/12 รอบสำหรับ 2/3/4 คน เริ่มด้วยเงิน 15 เหรียญและสิทธิ์ตรวจ 2 ครั้ง ไม่มีใครถูกคัดออก ก่อนเข้าตลาด ทุกคนเลือกหนึ่งในสามเส้นทางแบบปิดหรือผ่านได้ฟรี เสียงมากสุดชนะ เสมอสุ่ม หากทุกคนผ่าน server เลือกตลาดที่โอกาสคำสาปต่ำสุดก่อน

แต่ละตลาดเปลี่ยนโอกาสสร้างของแท้/คำสาป มูลค่า Demand และเงินจากเจ้ามือที่เติม pot ต่อรอบ อ่านตัวเลขบนหน้าตลาดก่อนตัดสินใจ โอกาสที่แสดงเป็นโอกาสสร้างสินค้าแต่ละชิ้น ผู้ขายยังเลือกหนึ่งจากสองชิ้น จึงไม่ใช่โอกาสของสินค้าที่นำมาขายโดยตรง

ช่วงผู้ซื้อรวมการตรวจและยื่นราคาไว้ด้วยกัน ตรวจได้ก่อนล็อกราคาเท่านั้น ราคา 0 คือไม่ซื้อ สามารถเลือกเดิมพัน 1–3 เหรียญว่าของมีหรือไม่มีคำสาป หรือไม่เดิมพันก็ได้ ผู้ขายเดิมพันไม่ได้ ราคาบวกเดิมพันต้องไม่เกินเงินที่มี ผู้ทายถูกแบ่ง pot ตามสัดส่วนเดิมพันที่ถูก ไม่มีผู้ทายถูกให้ pot ค้างรอบถัดไป เดิมพันจึงไม่ได้รับประกันกำไร

หลังตลาดแรกและตลาดที่สอง ทุกคนเลือกของเสริมส่วนตัวหนึ่งจากสามอย่างหรือข้ามได้ฟรี ของเสริมมีผลกับการซื้อหรือเดิมพันครั้งถัดไป ของที่ซื้อไปแล้วไม่ถูกคิดคะแนนใหม่ อ่านข้อแลกเปลี่ยน เช่น ผู้กลืนคำสาปทำให้คำสาปเพิ่ม 2 คะแนน แต่ของแท้ทุกชิ้นลด 3 คะแนน ผู้เดิมพันหนักเพิ่มเพดานเดิมพันเป็น 5 เหรียญ เริ่ม run ใหม่ เงิน สิทธิ์ตรวจ และของเสริมเริ่มใหม่ทั้งหมด

ก่อนเริ่ม ให้แต่ละคนตอบเองว่า: ตัวเลขโอกาสสร้างบอกผลสินค้าที่ผู้ขายเลือกแน่นอนได้หรือไม่ (**ไม่ได้**), เส้นทาง/ของเสริมเสียเงินหรือไม่ (**ไม่เสีย**), ของเสริมเปลี่ยนคะแนนของที่ซื้อแล้วหรือไม่ (**ไม่เปลี่ยน**), ราคาและเดิมพันรวมกันเกินเงินได้หรือไม่ (**ไม่ได้**)

หลังจบ จดเส้นทางหรือของเสริมที่ทำให้แต่ละคนเปลี่ยนราคา การตรวจ หรือเดิมพัน พร้อมเลขตลาด/รอบและเหตุผล หากยังเลือกเหมือนเดิม ให้บันทึกตรง ๆ เทียบสอง run ที่สุ่มใหม่โดยไม่ถือว่า RNG เพียงอย่างเดียวพิสูจน์ความสนุก ดูเกณฑ์ rematch สมัครใจด้านล่าง และดาวน์โหลด JSON ก่อนเริ่ม run ใหม่

## คำอธิบายเริ่มต้น v0.1 ที่เก็บไว้อ้างอิง

จับเวลาตั้งแต่เริ่มอ่านหรืออธิบายจริง ไม่ถือว่าการมีข้อความสั้นพิสูจน์ว่าเข้าใจแล้ว ผู้จัดอ่านได้ดังนี้:

> ทุกคนเริ่มด้วย 15 เหรียญ และผลัดกันเป็นผู้ขายกับผู้ซื้อ จบ 9 รอบเมื่อมี 3 คน หรือ 12 รอบเมื่อมี 4 คน คะแนนคือเงินเหลือบวกมูลค่าของที่ซื้อ ทุกคนอยู่จนจบเกม
>
> ผู้ขายเห็นความจริงของสองชิ้น แล้วเลือกขายหนึ่งชิ้น ความแท้กับคำสาปเป็นคนละคุณสมบัติ ของแท้มีคำสาปได้
>
> ผู้ขายไม่รับประกันก็ได้ หรือวาง 2 เหรียญรับประกันเพียงว่าแท้หรือไร้คำสาป ถ้ารับประกันผิดและขายได้ มัดจำไปให้ผู้ซื้อ และผู้ขายเสีย 2 คะแนน ถ้ารับประกันจริงหรือขายไม่ออก ผู้ขายได้มัดจำคืน
>
> ผู้ซื้อแต่ละคนมีสิทธิ์ตรวจ 2 ครั้งตลอดเกม แต่ละรอบเลือกตรวจได้หนึ่งคุณสมบัติ หรือเก็บสิทธิ์ไว้ ผลตรวจเห็นเฉพาะคุณ
>
> ทุกคนยื่นราคาแบบปิด ล็อกแล้วแก้ไม่ได้ ราคา 0 คือผ่าน ผู้ชนะจ่ายราคาของตนให้ผู้ขาย แล้วเปิดความจริงทั้งสองอย่าง ราคาเสมอสุ่มผู้ชนะ
>
> ของแท้มีค่า 9 คะแนน ของปลอม 1 คะแนน คำสาปหัก 6 คะแนน ถ้าเป็นของแท้ตรงความต้องการตลาด ได้อีก 3 คะแนน เงินเหลือก็มีค่า จึงต้องเลือกว่าคุ้มจ่ายเท่าไร

ให้แต่ละคนตอบเองก่อนเฉลย ไม่มีผู้เล่นคนอื่นตอบแทน จดเวลาและคำตอบลง [แบบบันทึก](session-template.md):

1. “รับประกันว่าแท้” บอกได้ไหมว่าสินค้าปลอดคำสาป? **ไม่ได้**
2. อยากไม่ซื้อรอบนี้ ต้องยื่นราคาเท่าไร และล็อกแล้วแก้ได้ไหม? **0; แก้ไม่ได้**
3. ซื้อของแท้มีคำสาปราคา 4 เหรียญ ไม่ตรง Demand: ของมีมูลค่ากี่คะแนน และเทียบกับการเก็บเงินไว้ คะแนนสุทธิเปลี่ยนเท่าไร? **3 คะแนน; ลด 1 คะแนน**

แยกเวลาอธิบายจากเวลาที่แต่ละคนตอบครบถูก หากต้องสอนเพิ่ม ให้บันทึกว่าจุดไหนยังสับสนและใช้เวลากี่วินาที ห้ามแปลง “อ่านจบในสองนาที” เป็น “เข้าใจในสองนาที” จากนั้นสอนให้เข้าใจก่อนเปิดแมตช์จริง และจดว่ารอบแรกเล่นเองได้หรือยังต้องช่วย

## ระหว่างเล่น

- ครั้งแรก **ไม่ใช้ voice หรือแชตเรื่องกลยุทธ์** ความช่วยเหลือเรื่องปุ่ม/กติกาบันทึกแยกได้ ไม่ปล่อยคนงงเพื่อรักษาเงื่อนไขทดสอบ
- ผู้จัดไม่เล่นแทน ไม่บอกราคาที่ควรยื่น และไม่ขอให้คิดดัง ๆ ระหว่างตัดสินใจ รอถามเหตุผลหลังจบ
- จดเหตุการณ์พร้อมเลขรอบ: ตัดสินใจเหมือนเดิมโดยไม่คิด, งง guarantee, ใช้สิทธิ์ตรวจไม่ตรงที่ตั้งใจ, รอจนเบื่อ, หมดเวลาหรือหลุด, reveal ที่จำได้
- แยก “ผู้เล่นกดผ่าน” จาก “server ผ่านให้เมื่อหมดเวลา” รวมถึงสาเหตุภายนอก เช่น Wi-Fi หรือมีธุระ
- รักษากติกาเดียวกันตลอด session ก่อนแก้ตัวแปร ต้องรู้ก่อนว่าปัญหาคือกติกา ความเข้าใจ หรือปุ่ม

## หลังจบและการเล่นซ้ำ

ให้ผู้เล่นตัดสินใจเองก่อนถามคำถามประเมิน ผู้จัดไม่เสนอรางวัล ไม่ขอช่วยเล่นอีกรอบ และไม่ใช้คะแนนสูงเป็นเหตุผลชวนต่อ จดว่าใครขอเล่นต่อเอง และกลุ่มเริ่ม/จบแมตช์ถัดไปจริงไหม

แบบบันทึกแยกสามอย่าง:

- **การขอเล่นซ้ำเอง:** คำขอหรือการเริ่มต่อที่เกิดก่อนผู้จัดถามเรื่อง rematch
- **ความอยากเล่นซ้ำเมื่อถูกถาม:** คำตอบส่วนตัวหลังบันทึกช่วงข้างต้น เก็บแยก ไม่ใช้แทนอัตราเล่นซ้ำจริง
- **การเล่นซ้ำจริงของกลุ่ม:** มีแมตช์ถัดไปโดยสมัครใจและจบครบ พร้อม audit ทั้งสองแมตช์ กลุ่มที่ถูกนัดให้เล่นสองเงื่อนไขตั้งแต่ต้นไม่ถือว่าแมตช์บังคับนั้นเป็น rematch สมัครใจ

ให้โอกาสเลือกหยุดหรือเล่นต่ออย่างชัดเจน จดกลุ่มที่ไม่มีเวลาเล่นต่อแยกเป็น **ไม่มีโอกาส** อย่านับเป็นปฏิเสธเกม และรายงานจำนวนที่ตัดออกด้วย

ถามส่วนตัวหลังเก็บการเลือก rematch: ช่วงไหนอยากตัดสินใจที่สุด, ช่วงไหนรอหรือเบื่อ, ใช้หลักอะไรเลือกตรวจ/ราคา, จุดไหนไม่เข้าใจ, reveal ไหนจำได้, ความสนุก 1–5 และอยากกลับมาเล่นอีกหรือไม่ เก็บคำตอบตรง ๆ รวมถึงเหตุผลที่ไม่เล่นต่อ

## วิเคราะห์หลักฐาน

ใช้ไฟล์ผลจากปุ่มในเกม ไม่ใช้ log ที่ถูกสร้างโดย bot มาปนกับ human playtest:

```sh
npm run --silent playtest:report -- /path/match-1.json /path/match-2.json > /tmp/cursed-market-playtest-report.json
```

เครื่องมือ replay ทุกแมตช์ ตรวจคะแนน/roster/timestamps ปฏิเสธไฟล์ซ้ำ และแยก timeout จากการตัดสินใจเอง รายงานการซื้อ/ผ่าน การเสมอ การตรวจ คำรับประกัน เงินกระจุก และเวลาของแต่ละ phase ไม่ส่ง seed หรือ event log ไปในรายงานสรุป

รายงานจาก log จะคง `humanFunValidated: false` และ `voluntaryRematchRate: null` เพราะ log อย่างเดียวบอกไม่ได้ว่าคนจริงเข้าใจ สนุก หรือเลือกเล่นต่อโดยสมัครใจ ต้องอ่านคู่กับแบบบันทึกของคนจริง

คำนวณสองอัตราจากแบบบันทึก พร้อมจำนวนจริง:

- ผู้เล่นขอเล่นต่อเอง / ผู้เล่นที่มีโอกาสเลือกจริง พร้อมจำนวนไม่ทราบ/ไม่มีโอกาส
- กลุ่มที่จบ rematch สมัครใจ / กลุ่มที่มีโอกาสเลือก rematch พร้อมจำนวนกลุ่มที่ถูกนัดให้เล่นต่อ

เป้าหมายประมาณ **70%** เป็นสัญญาณเริ่มต้นให้สำรวจ ไม่ใช่เส้นผ่านอัตโนมัติ รายงาน 1/1 กลุ่มเป็น 1/1 ไม่ใช้ 100% ยืนยัน replayability ผู้เล่นในกลุ่มเดียวกันไม่ใช่ตัวอย่างอิสระ

## การเปรียบเทียบและการแก้ครั้งแรก

หลังกลุ่มแรก ใช้กลุ่มอื่นทดสอบ voice/no-voice ด้วยกติกาเดิม สลับลำดับเงื่อนไขในกลุ่มถัดไปหากใช้คนเดิม เพื่อไม่สับสนว่าความสนุกเพิ่มเพราะ voice หรือเพราะเริ่มเป็น วาง session 2 คนแยกด้วย เพราะการแข่งขันและเงินหมุนต่างจาก 3–4 คน

อย่าสรุปว่ากลยุทธ์ชนะเสมอจากแมตช์เดียว ตรวจเหตุผลผู้เล่น เทียบหลายแมตช์ และหมุนบทบาท/คู่แข่งก่อนสรุป จากนั้นเลือก **ปัญหาหลักหนึ่งข้อ** พร้อมเหตุการณ์และคำพูดที่รองรับ เสนอการแก้เล็กหนึ่งอย่างแล้วทดสอบซ้ำ

ยังไม่ทำภาพใหม่ เสียง ระบบ progression หรือเนื้อหาเพิ่ม จนมีหลักฐานเชิงบวกว่าลูปเดิมชวนเล่นซ้ำ
