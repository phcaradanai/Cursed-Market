# ผลตรวจค่านายหน้า ความไว้ใจ และเงื่อนไข Dark Market

2026-10-14 ตาม [กติกาการค้าใหม่](../plan/Commerce_Trust_Market_v0.5.md) ใช้กับเกมใหม่ที่เปิด `commerce`; เก็บกติกาเครดิตจบรอบ/หัวก้อยก่อนหน้านี้ไว้

- **419 tests ผ่าน, 0 fail** (`npm test` รวม actual HTTP/WebSocket tests) และ **full build ผ่าน** ทั้ง server, legacy และ appraisal clients
- Commission/trust regressions ครอบคลุมซื้อเอง, ซื้อข้ามร้านพร้อมค่าแนะนำ, ส่วนลด/ดีลหลายชิ้น, ของไม่ได้ประเมิน, ซื้อไม่ได้แล้วไม่จ่าย, ฝากขายแล้วประมูลสำเร็จ, ขายต่อไม่จ่ายซ้ำ, request ซ้ำ, ความไว้ใจแยก NPC/เพดาน/การยอมรับราคาต่ำ, ราคา 0 และทรัพย์ของผู้ตายที่หยุดเปลี่ยน
- Market regressions ครอบคลุมโบนัสเครดิต/พลัง/ชีวิต/ผลดี, เงื่อนไขสองคุณสมบัติ, ลดราคา 20%, เสียพลัง/ชีวิต/รับผลเสียเพื่อราคาเต็ม, ไม่มีโบนัสเมื่อผิดเงื่อนไข, งบรวมโบนัส/การปล่อยงบส่วนเกิน, quota/เจ้าของ/packet ซ้ำ และการใช้ภูมิคุ้มกันแทนผลเสีย
- ตรวจจ่ายสิ่งแลกเปลี่ยนก่อนตรวจคุณสมบัติที่ซ่อนอยู่ เพื่อไม่ให้ใช้คำสั่งที่จ่ายไม่ได้เป็นเครื่องตรวจฟรี การมีผลเสียเดิมโดยไม่เสียอะไรเพิ่มใช้แลกราคาเต็มไม่ได้
- เปลี่ยนคุณสมบัติแท้/คำสาปที่ซ่อนอยู่แล้ว private DTO และ unknown preview ยังเหมือนเดิม ราคาค่านายหน้าไม่เปิดเผย hidden base; raw/room audits เก่า replay ผ่าน ชุด catalog/ตลาดเดิมระบุ `commerce:false` เพื่อคงการทดสอบ baseline พร้อมชุดใหม่ที่ตรวจ default commerce
- Seeded runs กติกาใหม่ผ่าน strict replay และตรวจงบรายการที่สร้างจริง กระบวนการสุ่มอยู่ฝั่ง server; build ยืนยันว่า browser bundle ไม่ดึง `node:crypto`

Ego Browser ตรวจ production bundle ผ่าน QA fixture บน loopback 3110 โดยใช้ state และ private view ของ engine จริงเพื่อจัดกรณี known match / known mismatch / unknown ให้อยู่หน้าจอเดียว ไม่อ้างว่า fixture เป็น run ปกติหรือใช้เป็น audit proof ตรวจ desktop **1440×1000** และ mobile **375×900**: ไม่มี horizontal overflow, ปุ่มขายสูงอย่างน้อย 44px และชื่อเงื่อนไข/โบนัส/สิ่งแลกเปลี่ยนปรากฏก่อนขาย

การกดผ่าน UI พิสูจน์ค่านายหน้า: ซื้อของที่ประเมินราคา 20 จากเครดิต 40 เหลือ **22** พร้อมความไว้ใจ Orc **3 → 4** และโอกาสยอมรับราคาต่ำเพิ่มเป็น 20 จุดเปอร์เซ็นต์ การขายตรงเงื่อนไขรับ 25 และชีวิต +1; การขายผิดเงื่อนไขแบบเต็มราคาจ่าย 1 ชีวิตและรับ 40; การขายของที่ยังตรวจไม่รู้แต่ผิดเงื่อนไขรับ 24 จากป้าย 30 โดยไม่รับโบนัส ตัวเลขทรัพยากรและข้อความหลังขายตรวจผ่าน UI
