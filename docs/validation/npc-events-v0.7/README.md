# Personal NPC events — 2026-10-15

Implemented request: one new optional event for each of eight merchants, including delayed Vampire and Alien contracts. All randomness remains seeded and server-authoritative. Live `appraisal-main.ts` enables `npcEvents`; exact historical configs without the flag preserve their original event schedules and replay. Eligible personal events have a 65% seeded offer chance at the start of appraisal, ahead of the existing event pools. Decline and timeout never accept a new contract.

| Merchant / event | Cost and result |
| --- | --- |
| Vampire / E109 | Pay exactly 2 life, leaving at least 1; damage shields/vulnerability do not alter this quoted price. On the next actual chosen Vampire encounter, roll one: free shelf item, 50% off the first own-shop purchase in that encounter, restore up to 6 energy, restore up to 3 life, or a random buff. Meaningless full-resource outcomes are excluded. A pending pact prevents another pact. No reward if the run ends first. |
| Alien / E110 | Seeded offer permits 1 up to 3 chosen distinct unlocked inventory items. They leave inventory and stop giving held effects. The same item IDs, hidden truths and learned knowledge are preserved in escrow. Selecting Alien from encounter `lentAt + 2` returns the original items plus 4–8 credits and up to 1–2 energy per item, using the same per-item RNG rate for proportional scaling. Reserve 8 credits per item when lending so later rewards remain payable. No second loan while one is pending. |
| Dark One / E111 | Roll 1–3 different payable cost types: credits, energy, life, an unlocked item. Show exact costs before consent. Choose an owned debuff to remove, or a living opponent to receive a seeded random debuff. Recheck all targets/costs before settlement; existing debuff shields still work. Dead spectators are excluded in both historical and survival rules. |
| Autometa / E112 | Choose one unlocked item or 2 energy for one seeded buff not already held. |
| Orc / E113 | Pay 2 energy for a random warrior boon. |
| Beast / E114 | Give one unlocked item; restore up to 4 energy and 2 life, plus one random guiding boon. |
| Deep Sea Monster / E115 | Pay 3 credits to reveal one unknown price/authenticity/curse fact on a shelf item, plus one random deep-sea boon. |
| The Swarm / E116 | Give one unlocked item for two distinct random boons. |

Reward/cost numbers and the 65% offer rate are assistant-selected provisional balance, not human playtest findings. Existing buff durations/charges, recovery modifiers and resource caps apply. Vampire 50% applies after flat discounts, rounds down, includes an optional two-item bundle, excludes fees and cross-shop purchases, and expires on advance.

**Explicit user decision:** if a run ends before Alien repayment, return every original loan item for final scoring, but award no bonus. This occurs before Collector settlement, including for dead spectators. Historical fixed-encounter wealth accounting keeps the principal throughout the loan. The private UI score estimate includes known loan principal and preserves its unknown-item count.
