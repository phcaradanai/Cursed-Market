# เบาะแสราคาหลังตรวจเท่านั้น

2026-10-14 · Survival รุ่นล่าสุด http://192.168.10.150:3111 · สร้างห้องใหม่

ผู้ใช้ไม่ต้องการให้แสดงช่วงมูลค่า เช่น “เบาะแส 18–24” ก่อนตรวจราคาสินค้าชิ้นนั้น เพราะทำให้การตรวจไม่มีประโยชน์

## การแก้

- ItemView ส่ง range เฉพาะเมื่อมี knowledge.range หรือ knowledge.base เท่านั้น ไม่เติมช่วงจาก catalog เป็นข้อมูลฟรี
- ItemFacts และ ItemCard อ่านข้อมูลที่รู้จริงต่อชิ้น ไม่ fallback ไปยังช่วงของชนิดสินค้า การ์ดทั่วไปไม่มีตัวเลขมูลค่า
- ตัวเลขความเสี่ยงจับผิดจะแสดงเมื่อมีข้อมูลมูลค่า ช่องราคาก่อนตรวจเริ่มจากราคาขายที่มองเห็นได้ ไม่ใช้ค่ากลางช่วงมูลค่าที่ยังไม่รู้
- ตรวจความแท้/ผลของสินค้าไม่เปิดข้อมูลราคา การตรวจชิ้นหนึ่งไม่เปิดอีกชิ้นหรือข้อมูลส่วนตัวให้ผู้เล่นอื่น
- ผลราคาที่เปิดเผยจากเหตุการณ์/ข้อมูลสาธารณะ และข้อมูล Collector ยังเป็นไปตามกติกาเดิม ไม่เปลี่ยน resolver, ค่าใช้พลัง หรือ seeded audits
- บอทใช้ราคาขายแทนช่วงราคาที่ไม่รู้เมื่อยังไม่มีข้อมูลตรวจ

## หลักฐาน

- npm test: 426/426 ผ่าน รวม 3 regression tests สำหรับ DTO/UI/tooltip/risk/default input และการตรวจราคาจริงเทียบการตรวจแบบอื่น
- build:server ผ่านใน npm test; build:client และ build:appraisal ผ่าน
- Impeccable detector: 0 findings สำหรับสองไฟล์ UI ที่แก้
- Browser fixture ใช้ production bundle: ก่อนตรวจไม่มีช่วงราคาและไม่มีเปอร์เซ็นต์ความเสี่ยง กดตรวจแล้วเห็น 14–19 พลังลด 8 → 7; mobile 375px ไม่มี overflow แนวนอน
- LAN ปกติไม่มี fixture: ก่อนตรวจ range ไม่มีและ knowledge ว่าง หลังตรวจได้ 7–11 พลัง 9 → 8 ส่วนสินค้าชิ้นถัดไปยังไม่มี range ดู [ผล LAN](price-knowledge-v0.5/lan-result.json)
