## การทดสอบ

- server, legacy client และ appraisal client builds ผ่าน

- สินค้าใหม่ทั้ง 18 ชนิดมี seeded generation → purchase → end-game audit replay จริงครบทุกชนิด แยกจาก fixture
- ทุกผลมี proof ถือสองชิ้นได้สองเท่า ขายออกแล้วลดผล และ catalog v2 ไม่ใช้ผลใหม่
- ตรวจฟรีที่พลัง 0, quota เพิ่มจากสมุด, แยกสิทธิ์ราคา/แท้/ผล, ไม่กิน B05/D01 เมื่อใช้สิทธิ์ฟรี, รีเซ็ตช่วงถัดไป และราคาไม่หลุดก่อนตรวจ
- ค่านายหน้า 20% + ค่าดำเนินการ 2, ความไว้ใจ +3, จ่ายครั้งเดียว, ของเพิ่งซื้อไม่เพิ่มค่านายหน้าดีลเดียวกัน, ส่วนลดชุด/พลังต่ำสุด 0 และบัญชีเงินรวมถูกต้อง
- ถุงมือเพิ่มโอกาสยอมรับราคาต่ำ สูงสุด 95% โดยไม่ให้ซื้อฟรีหรือเปลี่ยนความเสี่ยงจับผิด
- ดอกผลหลังช่วงและโบนัสหัวก้อยถูก snapshot; ทายผิดสูญยอดรวม; ทดสอบสุ่มแบบ seeded 3,000 ครั้งทั้งหัว/ก้อย ทั้งโบนัส 60% และเพดาน 85%
- ราคาตลาดตรงเงื่อนไข/ลดราคา/สละ ได้ 109/92/102 จากฐาน 100 ตามของถือสองชิ้นใน fixture; ตัวอย่างราคาตรงกับ resolver; ไม่นับชิ้นที่จะขายและไม่ข้ามสิทธิ์รับซื้อ
- HTTP/WebSocket integration: สิทธิ์ตรวจฟรีที่พลัง 0, ค่านายหน้า 20%, เงินหลังช่วง 14, หมวก 60% และ reset สิทธิ์ตรวจที่ช่วง 2
- Impeccable detector: 0 primary findings; sidecar advisories เดิมอยู่นอกขอบเขตนี้

## Browser

Production bundle บน fixture ที่ถือสินค้าใหม่ทุกชนิดอย่างละสองชิ้น ใช้เพื่อบังคับสภาพ UI ไม่ใช่หลักฐาน seeded replay:

- ก่อนตรวจไม่เห็นช่วงราคา; ตรวจราคาฟรีแล้วพลัง 3 → 3 และสิทธิ์ราคา 2 → 1
- ประเมิน 40 ซื้อจริง 38 โดยใช้ 0 พลัง และรับค่านายหน้า 9 (20% ปัดลง + ค่าดำเนินการ 2); เครดิต 200 → 171; ความไว้ใจ +3
- สรุป 36 ชิ้น / 18 ชนิด: 20% + 2 เครดิต, เงินหลังช่วง +4, หัวก้อย 60% ได้ครั้งละ 7, ตรวจได้ 4 ครั้ง
- หลังจบซื้อขายเริ่มรางวัล 14 และรับจริงทำให้เครดิต 171 → 185
- Desktop 1440×1000 / mobile 375×900: ไม่ล้นแนวนอน ข้อความสิทธิ์ฟรีบนกระดาษใช้ ink rgb(48,39,31); โอกาสต่อรองแสดงผลรวมถุงมือ 6 จุดเปอร์เซ็นต์พร้อมความไว้ใจ 0
